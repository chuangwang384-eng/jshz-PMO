## 二、接口清单

> 通用约定：
> - 数据格式：`application/json`（除下载类接口）
> - 编码：UTF-8；CSV 导出带 BOM，可直接用 Excel 打开
> - 员工接口默认**脱敏**（身份证、银行卡仅保留前 3 后 4），管理员接口通过 `sensitive=1` 获取完整数据

### 1. 专家数据查询接口

#### GET /api/experts

查询全部专家（默认脱敏），支持关键字模糊搜索。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| keyword | string | 否 | 搜索关键词，匹配姓名/单位/科室/职称/研究方向/擅长领域/联系方式/简介 |
| sensitive | int | 否 | `1` 返回完整字段（管理员用），缺省/`0` 返回脱敏字段 |

请求示例：

```
GET http://127.0.0.1:8000/api/experts
GET http://127.0.0.1:8000/api/experts?keyword=钱毅
GET http://127.0.0.1:8000/api/experts?keyword=医院&sensitive=1
```

返回示例（脱敏版）：

### 2. 选择后下载接口（新增）

#### GET /api/experts/selected/export

按选中 id 集合导出 CSV（默认脱敏，`sensitive=1` 完整）。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| ids | string | 是 | 逗号分隔的专家 id 集合，如 `ids=1,2,3` |
| sensitive | int | 否 | `1` 完整字段；缺省脱敏 |

请求示例：

```
GET http://127.0.0.1:8000/api/experts/selected/export?ids=1,2,3
GET http://127.0.0.1:8000/api/experts/selected/export?ids=1,2,3&sensitive=1
```

返回：`experts_selected_<时间戳>.csv`（UTF-8 带 BOM，15 列字段与整库导出一致）。

#### GET /api/experts/selected/zip

按选中 id 集合导出 ZIP 包（内含 `experts_selected.csv` + `photos/` 对应照片原图，脱敏规则同上）。

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| ids | string | 是 | 逗号分隔的专家 id 集合 |
| sensitive | int | 否 | `1` 完整字段；缺省脱敏 |

请求示例：

```
GET http://127.0.0.1:8000/api/experts/selected/zip?ids=1,2,3
GET http://127.0.0.1:8000/api/experts/selected/zip?ids=1,2,3&sensitive=1
```

返回：`experts_selected_<时间戳>.zip`。

### 3. 新增 / 修改 / 删除接口

#### POST /api/experts

新增专家（JSON 或 multipart 含照片）。

请求体（JSON 示例）：

```json
{
  "姓名": "李四",
  "单位": "南方医科大学坪山医院",
  "科室": "影像科",
  "职称": "主任医师",
  "研究方向": "医学影像",
  "擅长领域": "CT 诊断",
  "联系方式": "13900139000",
  "简介": "擅长 CT 影像诊断",
  "身份证号": "110101199002022345",
  "银行卡号": "6222020202020202",
  "修改人id": "admin"
}
```

新增时「身份证号」「银行卡号」「联系方式」为必填；照片通过 `multipart/form-data` 的 `照片` 字段上传（jpg/png/webp 等，≤5MB）。

返回：`201` + 完整专家对象（含自动生成的 id、创建时间、修改时间）。

#### PUT /api/experts/<id>

修改专家（按 id 定位）。请求体同上；「身份证号」「银行卡号」「联系方式」可暂空后补（已填则校验格式）。支持 multipart 上传新照片替换原照片。

返回：`200` + 更新后的专家对象；不存在返回 `404`。

#### DELETE /api/experts/<id>

删除专家（同时删除其照片文件）。返回：`{"ok": true, "id": <id>}`。

| `/api/experts/template` | GET | 下载 CSV 批量导入模板 | - |

### 5. 批量导入接口

#### POST /api/experts/import

批量导入 CSV（multipart 上传，字段 `file`）。

模板表头（10 列）：

```
姓名,单位,科室,职称,研究方向,擅长领域,联系方式,简介,身份证号,银行卡号
```

- 必填列：姓名、联系方式、身份证号、银行卡号
- 编码支持 UTF-8（含 BOM）/ GBK
- 按姓名去重，重复行跳过并在结果中给出失败明细

返回示例：

```json
{
  "success": 10,
  "failed": [
    { "line": 3, "name": "王五", "reason": "姓名已存在（重复）" }
  ],
  "total": 11

```

## 三、典型查询示例（curl）

```bash
# 1. 查询全部专家（脱敏，供员工页）
curl "http://127.0.0.1:8000/api/experts"

# 2. 按姓名/单位模糊搜索
curl "http://127.0.0.1:8000/api/experts?keyword=钱毅"

# 3. 管理员获取完整数据
curl "http://127.0.0.1:8000/api/experts?sensitive=1"

# 4. 按 id 集合导出 CSV（脱敏）
curl -o selected.csv "http://127.0.0.1:8000/api/experts/selected/export?ids=1,2,3"

# 5. 按 id 集合导出 CSV + 照片 ZIP（管理员完整）
curl -o selected.zip "http://127.0.0.1:8000/api/experts/selected/zip?ids=1,2,3&sensitive=1"

# 6. 新增专家（JSON）
curl -X POST "http://127.0.0.1:8000/api/experts" -H "Content-Type: application/json" \
  -d '{"姓名":"李四","单位":"南方医科大学坪山医院","科室":"影像科","职称":"主任医师","研究方向":"医学影像","擅长领域":"CT诊断","联系方式":"13900139000","简介":"CT影像诊断","身份证号":"110101199002022345","银行卡号":"6222020202020202"}'

# 7. 修改专家（敏感字段暂空后补）
curl -X PUT "http://127.0.0.1:8000/api/experts/1" -H "Content-Type: application/json" \
  -d '{"姓名":"张建国","单位":"南方医科大学坪山医院","科室":"人工智能实验室","职称":"教授级高级工程师","研究方向":"机器学习","擅长领域":"图像识别","联系方式":"13800138000","简介":"AI研究","身份证号":"","银行卡号":""}'

# 8. 删除专家
curl -X DELETE "http://127.0.0.1:8000/api/experts/1"
```

## 五、注意事项

1. **脱敏规则**：员工侧接口默认脱敏；管理员侧需显式传 `sensitive=1`。身份证号、银行卡号脱敏格式为「前 3 位 + **** + 后 4 位」。
2. **数据安全**：删除操作不可恢复（物理删除），批量操作前请先导出备份。
3. **照片字段**：为空表示暂无照片；照片文件位于服务端 `uploads/` 目录。
4. **接口变更**：正式版上线后接口路径保持一致，仅服务地址变化。
