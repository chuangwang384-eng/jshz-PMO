## 二、安装与配置要点

### 1. Java JDK 17 LTS

- 下载：Oracle JDK 17 LTS 或开源发行版（如 Temurin/OpenJDK 17）
- 安装：安装到 `<LOCAL_PATH> Files\Java\jdk-17`（示例路径）
- 配置环境变量：
  ```
  JAVA_HOME=<LOCAL_PATH> Files\Java\jdk-17
  PATH=%JAVA_HOME%\bin;%PATH%
  ```
- 验证：命令行执行 `java -version`，输出含 `17.0.x LTS` 即可

### 2. Maven 3.9+

- 下载：Apache Maven 3.9.x 二进制包（apache-maven-3.9.x-bin.zip）
- 解压到：`<LOCAL_PATH>`（示例路径）
- 配置环境变量：
  ```
  MAVEN_HOME=<LOCAL_PATH>
  PATH=%MAVEN_HOME%\bin;%PATH%
  ```
- 配置本地仓库（可选，默认 `%USERPROFILE%\.m2\repository`）
- 验证：命令行执行 `mvn -v`

### 3. Node.js 20 LTS

- 下载：Node.js 20 LTS（MSI 安装包，含 npm）
- 安装：默认路径 `<LOCAL_PATH> Files\nodejs`
- 验证：命令行执行 `node -v`（应输出 v20.x.x）、`npm -v`
- 建议：配置 npm 国内镜像加速依赖下载
  ```
  npm config set registry https://registry.npmmirror.com
  ```

### 4. MySQL 8.0

- 下载：MySQL Community Server 8.0
- 安装：选择「Server Only」即可；建议随安装设置 root 密码并记入密码本
- 初始化配置要点：
  - 字符集：`utf8mb4`（避免中文乱码）
  - 端口：默认 3306
  - 服务：配置为 Windows 服务自启动
- 建库与授权（示例）：
  ```sql
  CREATE DATABASE expert_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
  CREATE USER 'expert_app'@'localhost' IDENTIFIED BY '请替换为强密码';
  GRANT ALL PRIVILEGES ON expert_system.* TO 'expert_app'@'localhost';
  FLUSH PRIVILEGES;
  ```
- 验证：`mysql -u root -p -e "SELECT VERSION();"`

### 5. Git 2.4x

- 下载：Git for Windows（64-bit 安装包）
- 安装：默认选项即可；推荐选择「Git from the command line and also from 3rd-party software」便于脚本调用
- 配置基础信息：
  ```
  git config --global user.name "部署账号"
  git config --global user.email "deploy@example.com"
  ```
- 验证：`git --version`

### 6. Python 启动器（py，可选）

- 用途：Demo 环境快捷启动（`py server.py`），非正式版必需
- 安装：安装 Python 3.11 时勾选「Add python.exe to PATH」即自带 py 启动器
- 验证：`py --version`

## 三、部署顺序建议

1. 安装基础环境：Git → JDK 17 → Maven → Node 20 → MySQL 8.0
2. 配置全部环境变量后重启终端（或注销重登）
3. 逐项执行版本验证命令，确认版本号符合要求
4. 初始化 MySQL 数据库（建库、建用户、执行 `database/init.sql` 初始化表结构）
5. 拉取代码：`git clone <仓库地址>`
6. 构建后端：`mvn clean package -DskipTests`
7. 构建前端：`npm install && npm run build`
8. 部署启动后端服务，配置服务端口与数据库连接
9. 迁移数据：将 Demo 版 `experts.db` 数据导出为 Excel（.xlsx）/CSV/JSON，按正式版表结构导入 MySQL
10. 上传照片：将 Demo 版 `uploads/` 目录照片同步至正式版照片存储目录
11. 浏览器访问验证：员工页 `/`、管理员页 `/admin`、接口 `/api/experts` 返回正常
