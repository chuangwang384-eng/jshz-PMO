# 会前财务资料、确认报价归档与旧区块下线

## 目标与业务边界

- 会前财务资料按平台类、直付类和重点类沿用各自表单。平台类我方公司使用河南景帅、郑州华秀、河南偌君、河南云展汇、上海独家记忆、北京际格。直付细分类型使用有合同、无合同。
- 已有的会议日期、会议/项目名称和我方负责人分别读取项目举办日期、项目名称和总负责人。会议日期在编辑入口统一命名，支持单日和多日。部门和客户对接人初次填写时分别从团队、客户姓名带出，允许保存财务口径。地点使用自由文本。
- 会议预算制作阶段确认报价时生成一份 Excel 归档，显示在项目文件。草稿和下载不产生归档，确认相同报价内容复用版本，变更后确认生成新版本。
- 从项目详情全部阶段移除截图所示四张概览卡、预算与实际支出、全局专家名单、全局供应商名单和结算合同，以及对应弹窗、交互和专用前端 API 封装。保留当前阶段专用业务、编辑项目、项目文件、合规待办、日程参会专家、历史数据及共享后台能力。
