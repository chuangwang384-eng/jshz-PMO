# 专家库列表改造需求

日期 2026-11-07 · 状态：待评审

适用于专家库列表页（`ExpertList.vue`）。目标：三层结构（搜索筛选区 + 视图切换 + 专家内容区）、紧凑卡片、双视图、两级搜索、批量导出交互优化。

## 1. 现状事实（已核实，2026-11-07）

| 项 | 现状 | 位置 |
| --- | --- | --- |
| 页面结构 | 单一 toolbar（搜索框 360px + 权限按钮组）+ 卡片网格 + 分页 | `ExpertList.vue`（1367 行） |
| 搜索 | 单框统一检索姓名/单位/科室/职称/联系方式/简介，仅 `keyword` 一个参数 | 后端 `ExpertController.list` → `ExpertService.pageList` |
| 卡片 | 头像 128px、卡片高度较高，一屏可浏览专家少 | `.expert-card` |
| 视图 | 仅卡片视图 | 无列表视图 |
| 导出 | 按权限分支：有 `expert:export` 权限显示"下载全量 Excel/含照片 ZIP"；否则显示两个"下载选中"按钮（未勾选时置灰但仍占空间） | toolbar |
| 勾选 | 跨搜索/翻页保留，已选姓名条展示 | `selectedIds`/`selectedExperts` |
| 数据模型 | `expert_info`：姓名/单位/科室/职称/研究方向/擅长领域/联系方式/简介/身份证号/银行卡/照片/身份证正反面/更新时间/修改人；**无省/市/地区字段** | `Expert.java` |

## 2. 目标与非目标

**目标**：紧凑卡片提升一屏浏览量；列表视图提升管理效率；两级搜索（统一检索 + 高级筛选组合）；导出交互去噪音。

**非目标（本期不做）**：
- 不改专家详情弹窗、新增/编辑审批流、照片上传与脱敏逻辑。
- 不改导出文件的内容与格式（Excel/ZIP 内容不变）。
- 不做卡片的内联编辑（仍点卡片进详情）。
- 权限模型不变（`expert:add`/`expert:export`/`expert:edit`）。

## 3. 需求范围

### P0 三层结构与紧凑卡片（默认卡片视图）

1. 页面改为「搜索筛选区 → 视图切换 + 工具行 → 专家内容区」三层结构。
2. 紧凑专家卡片：头像 128px → **72～88px**，卡片高度约 180～220px；姓名/单位/科室一行视线内可读；保留更新时间等元信息与勾选框；点击仍进详情。

### P0 列表视图

1. 新增列表视图（表格）：列建议为 姓名 / 单位 / 科室 / 职称 / 联系方式 / 更新时间 / 操作（查看详情）；勾选列与卡片视图一致（`!canExport` 时显示）。
2. 视图切换为图标切换（卡片 ⋮⋮ / 列表 ☰），**两种视图共用搜索条件、排序与勾选状态**；切换不清空数据与勾选。
3. 视图偏好按会话记忆（本期不做按账号持久化，避免再加接口）。

### P0 两级搜索

1. **基础搜索**：单框统一检索（姓名/单位/科室/职称/联系方式/简介关键词），宽度加大（约 480px），回车即搜。
2. **高级筛选**：折叠面板展开后组合使用，支持**一键重置**：

| 字段 | 控件 | 数据来源 |
| --- | --- | --- |
| 工作单位 | 可搜索下拉 | 后端字典接口（去重） |
| 所属科室 | 可搜索下拉 | 后端字典接口（去重） |
| 专家职称 | 多选下拉 | 后端字典接口（去重） |
| 专家照片 | 已上传 / 未上传 | 后端按 `photo` 字段判断 |
| 最近更新时间 | 日期范围 | 后端按 `update_time` 判断 |

**所在地区（省市级联）与档案状态（完整/待完善）两个字段本期不做**，原因见 §5 决策点（数据模型无地区字段、档案完整性无定义），待 Owner 决策口径后另开需求。

### P1 导出与批量操作交互

1. 默认状态只展示「新增专家」+「导出」入口（导出为下拉：Excel / 含照片 ZIP；有 `expert:export` 权限走全量导出，无权限走选中导出，权限规则不变）。
2. 勾选专家后出现**悬浮批量操作栏**（固定底部）：已选 N 位 + Excel/ZIP 两个动作 + 清空；既有勾选跨搜索/翻页保留、已选姓名条保留。
3. 「专家单位查询」外链保留（移入高级筛选区旁或工具行右侧）。

## 4. 交互规则

| 场景 | 预期 |
| --- | --- |
| 修改任一筛选条件 | 回到第 1 页重新加载；勾选保留 |
| 一键重置 | 高级筛选全部清空并重新加载；基础搜索关键词保留（由清空按钮单独负责） |
| 切换视图 | 数据、勾选、页码保持 |
| 勾选后未导出 | 悬浮批量栏常驻显示已选数量 |
| 高级筛选生效中 | 搜索筛选区显示已启用条件计数徽标 |

## 5. 需要 Owner 决策的事项

1. **所在地区筛选**：`expert_info` 无省/市字段。选项 A：本期去掉该筛选；B：从单位名称模糊推断地区（不可靠，不建议）；C：新增省/市字段（涉及数据补录与编辑表单，超出本期）。建议 A。
2. **档案状态（完整/待完善）**：系统无该字段与完整性定义。选项 A：本期不做；B：定义规则（如：照片+身份证正反面+银行卡+联系方式齐全=完整）并由后端计算。建议 B 但需 Owner 确认规则后再排期。
3. **后端扩展**（本期必须）：列表接口新增筛选参数（单位/科室/职称多选/照片状态/更新时间范围）+ 单位/科室/职称去重字典接口（登录可用）。确认后随本期发布。
