## 3. 背景与目标

### 3.1 业务背景

当前 jshz-PMO 系统已具备知识星球、项目管理、审批、消息、公告、供应商、客户、专家库等完整业务模块，但存在以下效率痛点：

1. **入口分散、反复跳转**：员工每天需要在知识星球、项目列表、个人中心之间来回切换才能找到自己的收藏、自己负责的项目和待办事项。
2. **收藏不聚合**：知识星球收藏功能已存在（`knowledge_favorite` 表 + 我的收藏接口），但仅存在于知识星球页内，个人中心没有聚合展示。
3. **"我的项目"无快捷视图**：项目数据能力完备（`ownerId/executorId` 筛选 + 阶段推进历史），但前端需要手动选择筛选条件才能看到"我负责的项目"，无法一键直达。
4. **全局搜索缺失**：系统内均为模块内局部搜索（知识文档 keyword、客户搜索、专家检索等），无跨模块全局搜索能力。

> 事实基线详见《jshz-PMO项目现状调研报告.md》与《全局搜索权限与脱敏调研.md》，所有设计均基于代码与数据库真实情况。

### 3.2 产品目标（SMART）

1. 员工登录系统后 5 秒内到达个人工作台，找到自己要的信息或入口。
2. 一期交付完整闭环：固定分区工作台 + 六类分组全局搜索 + 8 个固定快捷入口，覆盖全员。
3. 人均每日跨模块跳转次数明显下降（上线后通过埋点验证）。

### 3.3 用户画像与角色

| 角色 | 核心诉求 | 工作台呈现 |
|------|---------|-----------|
| 普通员工 | 快速看到自己的收藏、待审批、未读消息、公告，快速进入常用模块 | 收藏卡片 + 我的申请卡片 + 消息角标 + 公告 + 快捷入口 |
| 项目经理 / 项目负责人 | 额外关注自己负责/执行的项目走到了哪一步 | 在普通员工内容基础上，自动显示"我的项目"增强卡片 |
| 管理员 | 与普通用户一致，但项目可见范围覆盖全部（已有 `project:view-all`） | 同普通员工 + 全部项目 |

> 角色差异化采用**自动判定**，不依赖管理员维护规则：只要用户存在"自己作为负责人或执行人的未取消项目"，即显示"我的项目"卡片区；否则隐藏该区。

## 7. 详细功能说明

### 7.1 F1 工作台入口与路由

- **功能描述**：登录成功后默认跳转个人工作台 `/dashboard`；侧边菜单保留"个人中心" `/profile` 入口。
- **前置条件**：用户已登录。
- **主流程**：
  1. 用户登录成功，前端路由守卫将默认落地页从 `/experts` 改为 `/dashboard`。
  2. 侧边菜单新增"工作台"项（若原默认首页 `/experts` 为菜单项，则工作台置顶）。
  3. 工作台加载时调用聚合接口拉取各卡片数据。
- **异常流程**：聚合接口失败 → 对应卡片显示占位与重试入口，不影响其他卡片与搜索功能。
- **后置条件**：工作台成为系统第一屏。

### 7.2 F2 固定分区布局

- **功能描述**：顶部全局搜索条；主体分区：收藏卡片区、我的项目卡片区（条件显示）、我的申请/消息/公告区（并排）、快捷入口区（底部或独立区）。
- **前置条件**：无。
- **主流程**：页面按固定栅格渲染各分区。
- **异常流程**：无。
- **后置条件**：无。

### 7.3 F3 知识星球收藏卡片

- **功能描述**：展示当前用户最近收藏的 8 条知识文档（标题、分类、收藏时间倒序）。
- **前置条件**：用户已登录；知识星球收藏接口可用。
- **主流程**：
  1. 聚合接口返回 `favorites`（最近 8 条）。
  2. 点击某条 → 跳转知识星球对应文档详情/预览。
  3. 点击"查看全部" → 跳转 `/knowledge-planet` 并切到"我的收藏" tab。
- **异常流程**：收藏为空 → 显示空态文案"暂无收藏，去知识星球看看"。
- **后置条件**：无。

### 7.4 F4 我的项目卡片（增强卡片）

- **功能描述**：自动判定展示当前用户作为负责人或执行人的未取消项目，卡片含：项目名、当前阶段、负责人、状态、最近推进记录（时间）、到期时间、即将到期/逾期预警标记。
- **前置条件**：用户已登录；项目列表接口支持 `ownerId/executorId` 与行级过滤。
- **主流程**：
  1. 后端按当前用户 ownerId/executorId 查询未取消（非 DELETED）项目。
  2. 关联 `project_phase_history` 取最近推进记录；关联到期时间计算预警（如 7 天内到期标记"即将到期"，已过期未完成标记"已逾期"）。
  3. 点击卡片 → 进入项目详情 `/project/{id}`。
- **异常流程**：无负责项目 → 该区隐藏；项目数据异常 → 显示空态。
- **后置条件**：无。

### 7.5 F5 我的申请卡片

- **功能描述**：展示待我审批的数量角标 + 最新 3 条待办（申请主题、提交人、时间）。
- **前置条件**：用户已登录；`/api/approval/my-applications` 等接口可用。
- **主流程**：
  1. 聚合接口返回待办数量与最新 3 条。
  2. 点击卡片/角标 → 进入 `/profile/my-approvals`。
- **异常流程**：无待办 → 显示"暂无待办事项"。
- **后置条件**：无。

### 7.6 F6 未读消息

- **功能描述**：未读数字角标 + 最新 3 条未读消息（标题、时间）。
- **前置条件**：用户已登录；消息接口可用（已有本人通知分页/未读数）。
- **主流程**：
  1. 聚合接口返回未读数与最新 3 条未读。
  2. 点击 → 进入 `/profile/notifications`。
- **异常流程**：无未读 → 显示"暂无新消息"。
- **后置条件**：无。

### 7.7 F7 最新公告

- **功能描述**：最新 3 条生效公告（标题、发布日期、已读/未读标记）。
- **前置条件**：用户已登录；公告接口可用（仅 ONLINE + 生效中）。
- **主流程**：
  1. 聚合接口返回最新 3 条 ONLINE 且生效中的公告，附带当前用户已读状态。
  2. 点击 → 进入 `/profile/announcements` 对应公告详情。
- **异常流程**：无公告 → 显示空态。
- **后置条件**：无。

### 7.8 F8 全局搜索

- **功能描述**：顶部搜索框输入关键词，跨知识文档、专家、项目、客户、供应商、公告六类检索；结果按模块分组，每类前 5 条 + "查看全部"跳对应模块列表页（携带搜索词）。
- **前置条件**：用户已登录；关键词非空（长度 ≥ 1）。
- **主流程**：
  1. 用户输入关键词（防抖约 300ms）或回车触发搜索。
  2. 后端聚合六类结果，按模块分组返回。
  3. 前端分组渲染；点击结果跳转对应详情；点击"查看全部"跳模块列表页并带 keyword。
- **异常流程**：无结果 → 显示"未找到与'关键词'相关的内容"；接口超时 → 提示重试。
- **后置条件**：无。
- **权限规则**（关键）：搜索结果完全沿用各模块现有可见性规则——
  - 项目：仅返回当前用户可见项目（无 `project:view-all` 时仅本人负责/执行；隐藏 DELETED）
  - 知识文档：仅上架（status=1）
  - 公告：仅 ONLINE 且生效中
  - 专家：按现有检索逻辑，全员可查（与列表页一致，不额外脱敏）
  - 客户/供应商：按现有查看权限（登录即可）

### 7.9 F9 快捷入口

- **功能描述**：固定 8 个入口：知识星球、项目管理、专家库、客户信息、供应商、我的申请、公告、通讯录。
- **前置条件**：无。
- **主流程**：图标 + 名称平铺展示，点击跳转对应路由。
- **异常流程**：无。
- **后置条件**：无。

## 8. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 工作台聚合接口 P95 ≤ 500ms（内网）；全局搜索聚合接口 P95 ≤ 1s |
| 安全 | 沿用现有 JWT + RBAC；不新增权限码；搜索结果遵循各模块可见性规则 |
| 兼容 | Chrome / Edge 最新两个大版本；分辨率 1366x768 及以上 |
| 可靠 | 工作台各卡片接口独立失败降级（卡片级占位 + 重试），单卡片失败不影响整体 |
| 可维护 | 全局搜索聚合按模块实现可插拔检索器，后续新增模块只需注册检索器 |
