## 3. 背景、目标与用户

工作台是个人事项处理入口，帮助员工先看到需要处理的事情与到期风险，再访问项目、收藏、公告和常用模块。

- 普通员工：查看退回修改、本人申请进度、消息、个人项目及资料。
- 有审批权限人员：额外处理当前确实轮到本人审批的事项。
- 项目负责人/执行人：查看个人项目的阶段、最近变更与截止风险。
- 管理员：默认同样展示本人项目；另提供有权限的“全部可见项目”入口，不把管理权限等同于个人关系。

目标及测量：页面在约定测试环境中导航后 5 秒内可操作；使用不少于 5 名员工完成“找待办、找风险项目、找收藏、搜索目标”四类固定任务，至少 80% 的任务可在页面可操作后 5 秒内定位入口。跨模块跳转数使用相同任务对旧入口和新工作台作对比并记录，不预先宣称下降。持续埋点不作为一期依赖。

## 4. 范围与里程碑

一期 Must：F1 默认入口与上下文保留、F2 固定布局、F3 本人收藏、F4 本人项目与风险、F5a 本人申请、F5b 待我审批、F6 未读消息、F7 生效公告及已读状态、F8 六类全局搜索、F9 固定快捷入口、错误降级与安全验收。

一期拆为 M1 工作台聚合与处理闭环、M2 六类搜索两个子里程碑，各自验收；一期整体完成仍要求 M1、M2 均通过。阶段名称、最近阶段变更、项目预警和公告已读是 Must，不再同时列为 Should。

后续优先：企业合规待办、项目缺失材料、个人固定/排序常用入口、最近访问。合规待办必须遵守逐人新旧版切换与资源权限，不能跨版本合计；缺材料属于推进阻塞提示，不等同截止待办。

本期不做：独立任务引擎、日历/考勤/报销、拖拽布局、推荐引擎、AI 问答、OCR、新搜索引擎、搜索历史/热搜、换肤、持续行为埋点。首期为 PC 浏览器验收，不含手机专用布局；不影响已有模块访问方式。

## 5. 布局与首屏

固定信息顺序：

1. 全局搜索与精简快捷入口。
2. 待处理摘要：待我审批、退回待修改；项目风险摘要分别显示逾期、今天到期、未来七天到期。
3. 待处理具体条目，展示来源、标题、时间与操作入口；本人申请进度独立呈现。
4. 我的项目，继而收藏、公告、消息。

1366×768、浏览器 100% 缩放下，首屏须可见待处理摘要、到期风险摘要和至少一条有数据的待处理/风险项目入口；不能以收藏长列表挤出这些内容。没有事项时展示明确空态与常用入口。加载使用卡片骨架，不阻塞整个页面。

审批、退回修改、项目风险和未读消息分别计数；消息提醒与其关联业务事项不得重复相加成“总待办”。摘要数量表示全部符合条件记录，不是当前截取条数。

## 6. 功能与规则

### F1 工作台入口

无合法原目标时，登录成功进入 /dashboard；新增工作台置顶入口，保留 /profile。根路由与 Login.vue 默认回退一并调整。合法内站 redirect 优先；会话过期重登、刷新、浏览器前进后退、业务深链、强制改密后继续原合法目标。禁止外站和协议相对地址，沿用现有认证控制，不放宽权限。

### F3 收藏

当前用户最近收藏 8 条，按收藏时间降序、ID 降序稳定排序，显示标题、分类、收藏时间。“查看全部”打开我的收藏筛选，条目定位预览。下架/删除文档不展示；下架保留收藏关系，上架后恢复；总数和列表均按可见数据计算。空态为“暂无可用收藏，去知识星球看看”。

### F4 我的项目与风险

- 本人范围是负责人为本人 OR 执行人包含本人，项目 ID 去重；所有角色一致。无项目时隐藏列表，摘要显示无相关风险；查询失败不能当成无项目隐藏。
- DELETED 全部隐藏；CANCELED 不进入个人进行中列表和风险统计，可从既有项目列表查询；已完成项目不进入个人进行中列表和风险统计。
- 管理员“全部可见项目”仅为已有权限下的独立入口，不改变本人卡片的计数。
- 卡片最多 6 条：项目名、本人关系、负责人、项目状态、项目快照中的当前阶段、最近阶段变更（推进/回退及时间）、endDate 与风险。没有历史显示“暂无阶段变更记录”，不把普通更新时间冒充推进时间。
- 截止日期指项目 endDate，不代表阶段截止日期；没有日期显示“未设置结束日期”，不产生日期风险。
- 以服务端 Asia/Shanghai 自然日 today 计算 d=endDate−today，前端不得以本机时区独立重算。

| 条件 | 展示 / 风险组 |
| --- | --- |
| 未完成且 d<0 | 已逾期（红），逾期组 |
| 未完成且 d=0 | 今天到期（橙），单独计数，不算逾期 |
| 未完成且 1≤d≤7 | 即将到期（橙），包含第七天 |
| 未完成且 d>7 | 正常，无告警 |
| 未完成且 endDate 为空 | 未设置结束日期，不计风险 |
| 已完成 / CANCELED / DELETED | 不告警、不进进行中列表 |
| 完成状态未确定或配置异常 | 明示“完成状态待核实”或“配置异常”；不归正常、不捏造逾期，单独返回未知数 |

排序：逾期 → 今天到期 → 未来七天到期 → 其他未完成 → 完成状态未确定。组内 endDate 升序、空日期最后、ID 升序。风险摘要全量计算，最多 6 条只是显示截取。

**完成判定（负责人2026-11-04已选择）**：仅复用历史“已完成”阶段。实现限于 origin=LEGACY_BASELINE、schemaVersion=1 且哈希校验通过的项目快照：快照包含且仅包含一个历史“已完成”阶段、当前阶段属于该快照时，到达该阶段为COMPLETED；位于该历史流程其他阶段为INCOMPLETE，回退后重新计算。CREATED快照、缺历史完成阶段或来源不明的流程均为UNKNOWN。不能用最后阶段、当前全局阶段名称、日期已过或材料齐全猜测完成；不新增完成字段、不回填或修改原项目。其他类型暂待核实是本次批准的保守范围，验收应验证提示与统计隔离，不把UNKNOWN伪报成正常或完成。


### F5a 我发起的申请

展示本人最近 3 条申请及状态，提供待审批、退回修改数量；“待审批”明确表示等待别人处理，不列入本人可操作待办。退回修改单独进入首屏待处理区。条目展示主题、类型、申请时间与状态；点击定位申请记录，退回项进入现有重新编辑提交流程。撤回、重提后刷新。

### F5b 待我审批

仅满足既有审批权限及当前节点/指派/加签规则、当前确实可由本人执行审批动作的记录进入列表与数量。不得用全体待审数、历史参与者或仅有 approval:audit 代替可操作性判断。最多 3 条，按进入当前待处理节点时间升序、ID 升序；若当前模型缺节点时间，使用申请创建时间作为明确降级字段，界面标为申请时间。

无审批权限则不展示审批区与计数；有权限但暂无事项显示空态。点击定位审批记录并打开既有处理界面；转办/加签/审批后更新数量，再次操作由服务端重新校验。不新增工作台快捷批量审批。

### F6 消息、F7 公告与处理闭环

- 消息显示未读总数及最新 3 条，时间和 ID 降序；点击具体通知，成功加载通知内容后按现有接口已读，再进入允许的业务目标；目标无权限/不存在时展示通用提示，保留返回消息中心入口。
- 公告仅 ONLINE 且当前生效、当前用户可见的记录，最新 3 条，发布时间和 ID 降序；存在置顶规则时沿用模块统一排序。进入工作台不记已读，成功打开详情后才按既有规则记录。
- 所有条目定位具体对象；申请/审批需要列表弹窗定位时，不得只停留在列表首页。分页中找不到的目标通过授权详情查询定位，不绕过数据范围。
- 详情处理成功、撤回/重提、已读等操作后，返回 /dashboard 触发新查询，相关列表及数量在返回后 2 秒内开始刷新；接口未成功时保留错误提示，不能假显示新数量。
- 初次进入、路由返回、失焦后再次聚焦均刷新（同一秒内合并）；可见页面 60 秒轮询，隐藏暂停，恢复立即刷新；日期跨北京时间午夜重算。请求重叠采用最新请求有效原则。
- 条目处理后可能消失或排位改变；返回保留工作台滚动位置并显示刷新状态。401 统一进入现有登录流程，403/404 提示无权限或不可用，不泄露资源内容。

### F8 六类全局搜索

知识文档、专家、项目、客户、供应商、公告固定分组；每组最多 5 条，并提供可用结果总数和“查看全部”。零条显示本组无结果；无权限模块整组不出现，也不返回数量。错误不能作为零条。

- 输入去首尾空白，长度 1–100 Unicode 字符；空输入清空结果并取消请求，超长不请求且明确提示。
- 300ms 防抖；中文输入法 compositionstart 至 compositionend 不搜索、不以 Enter 选结果；组合结束后再防抖。普通 Enter 立即检索，已有键盘选中项时 Enter 打开；上下键选择、Esc 关闭、Tab 正常移焦、清空按钮恢复输入。
- 发送新搜索或清空时取消旧请求，并以序号兜底忽略旧响应；失败重试使用当前关键词。搜索词高亮按纯文本处理，禁止注入 HTML。
- 字段：知识标题/文件名/已有可检索正文；专家姓名/单位；项目名称/编号（当前模型编号映射为项目数字ID）；客户名称；供应商名称/类型/城市；公告标题/正文。字段映射由开发核对真实模型，不能假设不存在的列；预览和查看全部采用相同字段、过滤及排序。
- 排序统一为标题精确 → 标题前缀 → 标题包含 → 其他字段命中；组内更新时间降序、ID 降序，无更新时间使用 ID。不依赖数据库默认排序。
- LIKE 的 %、_、反斜杠作为普通文本查询，参数化 SQL；大小写在服务层约定为拉丁字符不区分，中文按字面匹配，数字按字面包含。知识正文不可提取时仅匹配元数据，不承诺 OCR。
- 搜索先执行模块访问与资源过滤，再计算数量及截取；全局项目搜索为当前用户全部可见项目，不是工作台本人筛选；排除 DELETED，取消项目按原模块可见规则处理。文档仅上架，公告仅上线生效，其他模块沿用现有权限、删除及敏感字段保护。
- 预览只显示必要标题和业务辅助字段，不展示身份证、银行卡、联系方式等。结果在点击时重新鉴权；权限撤回后不得从旧缓存获取内容或数量。
- 单模块超时/失败保留其余结果并标记失败分组，可重试；整请求失败独立展示。全部有权分组均查询成功且均为零时，才显示“未找到相关内容”。

### F9 快捷入口

固定 8 个：知识星球、项目管理、专家库、客户信息、供应商、我的申请、公告、通讯录。按现有模块权限展示；“固定”指配置固定，不强制向无权限用户显示入口。入口使用真实路由；常用入口排序/固定后续再做。

## 7. 非功能、安全与数据

- 现有 JWT/RBAC、资源隔离及脱敏继续生效，不新增权限码；本人身份只能由后端认证上下文取得。模块错误与拒绝不能绕过鉴权。
- 首期不新增业务表、不建立用户间共享缓存；如确需数据结构变更，另行提供迁移与批准。不得将“无新表”变成跳过正确性验证的理由。
- Chrome/Edge 最近两个大版本，1366×768 及以上；键盘操作和可读焦点状态；风险同时使用文字与颜色。
- overview P95≤500ms、搜索 P95≤1s 为待测目标；服务端总超时分别 1500ms、2000ms，前端分别 3s、4s；部分成功可返回，慢查询记录模块和耗时而不记正文/搜索词。
- 性能报告须记录代码版本、硬件、浏览器、网络、各模块可见/总记录量、索引、冷热状态；内网同环境分别以 1 与 20 并发、预热后各 1000 请求测 P95/错误率，并单测首屏。故障注入与冷启动结果单列，不混入正常请求指标；没有达标则优化/评审，不宣称通过。
- 默认不采集原始搜索词、正文或敏感业务字段；后续埋点仅可内网受控存储、最小字段与限定留存，经专项确定后实施。本期使用人工任务测量记录，无外部统计 SDK。

## 9. 依赖、风险与实施前门槛

1. A5按负责人批准的历史快照范围验收；其他类型的完成语义仍待后续业务确认，不得私自新增完结规则。
2. 审批可操作性必须复用现有动作规则，不能仅复用审批历史列表过滤。
3. 目标页 query 定位和搜索字段统一需要配套开发，原页面目前不能视为已支持。
4. 并行查询不保证低成本，尤其正文 LIKE 与总数统计须压测；超时和线程池隔离须验收。
5. 实施需同步架构、API、部署/测试与交接；本次仅替换需求与设计，不代表代码、权限或数据库已变更。
