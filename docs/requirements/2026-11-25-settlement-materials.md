# 结算资料上传

## 已确认的本期范围

按《结算流程上传口配置表》U01–U19、八个小节提供上传与资料核对。14 个通用口适用于所有项目，U14–U16 仅直付，U17–U18 仅平台。重点和未分类项目只使用通用口。项目负责人推进时，服务按适用上传口逐项核对必填。未发生酒店、其他供应商或劳务费用时，U01、U02、U03、U07 可由项目成员填写原因并标记不适用。U09 支持补传，或选择并复制本项目已归档的报价或预算资料，作为本阶段的独立版本。

表列多版本口每次提交形成一批，最新版为当前，有历史可查。其余上传口保留当前批次，每批可上传多文件。进入后续阶段后历史资料可预览下载，平台 U18 仍允许项目成员提交补件。已取消项目只读。历史普通阶段附件仍可查看，由成员重新按口归档后才计入推进检查。

建议上传和核对角色、业务时限显示为提示。项目阅读者可查看，写操作沿用项目成员（含超管）权限。文件支持 PDF、Excel、Word、常用图片、压缩包、TXT、OFD，每批最多 20 个、合计 50 MB。

## 后续排期候选

1. 审批流与内审。确认各上传口上传/审核角色，是否需要按资料口审批、退补、留痕和客户确认后解锁。确认直付盖章开票邮寄、平台提交与回执、内部报销的状态节点。
2. 自动提醒。确认 U07 七个工作日的起算节点、工作日历与接收人。U10 两个工作日只针对经我司支付费用版本。U18 在收到平台补件要求当天提交，需要可记录要求到达时间和通知对象。
3. 自动计价与单据。确认不合规项目 10% 转化费用计费基数、舍入、例外和审核，再考虑自动计算。确认成本单和结算单模板以及与项目预算、付款和财务报销的联动。
4. 按平台拆分劳务和合规材料。先补齐平台差异清单、必要材料和变更维护责任。
