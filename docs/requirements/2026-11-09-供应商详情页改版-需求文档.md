## 1. 背景与问题

详情页当前是「左中右三栏 + 通栏卡片堆叠」：左栏 11 个字段纵向平铺，中栏把图片、历史价格、评价、绑定四块全部铺开，右栏同城导航用多行彩色标签筛选。问题：

1. **信息层级弱**：名称、类型、城市、地址、联系人、电话、微信、评分、建档人、建档时间、描述 11 个字段等权排列，高频信息（联系人/电话）与低频管理信息（建档人/建档时间）混在一起。
2. **页面被图片挤占**：两张图片即占满中栏，历史价格和评价被推得很远。
3. **图片命名语义不清**：「图片命名」输入框与「上传图片」并列，用户不知道命名作用于哪张图。
4. **历史价格不可比**：只有品名/价格/单位/备注，没有报价日期与有效期，无法判断报价时效，也无法跨时间比较。
5. **评价以表单为主**：详情页底部直接是评分输入区，查询场景被迫看到录入控件。
6. **同城导航占位多、名称被截断**：多行彩色类型标签占空间，供应商名称 `ellipsis` 截断，且无法一眼看出当前档案在列表中的位置关系。

## 2. 改造目标

详情页第一职责是**查询**，第二职责才是维护。改造后：默认看到的是清晰分组的档案 + 可比较的价格 + 历史评价；图片、录入类操作收进各自 Tab 或弹窗。

## 3. 需求明细

### 3.1 基本信息：密集字段 → 分组档案

| 分组 | 字段 | 呈现 |
|------|------|------|
| 基础资料 | 供应商名称、所属城市/地址、供应商类型 | 名称最大号（19px 加粗），城市与地址合并一行，类型单独一行 |
| 联系信息 | 联系人、联系电话、微信 | 两列布局（联系人/电话并排），电话与微信带**复制按钮**，悬停提示「复制电话/复制微信号」 |
| 业务介绍 | 描述 | 独立分组，1.8 行高，保留换行 |
| 档案信息 | 建档人、建档时间、最近更新、综合评分 | **默认折叠**，点击标题展开；以 4 列栅格呈现 |

约束：

- 联系人与电话必须比建档时间更醒目——它们位于第二分组且正文字号 15px，档案信息为 14px 且默认折叠。
- 复制走 `navigator.clipboard`，非安全上下文（http）回退 `execCommand('copy')`，确保内网 http 访问也能复制。

### 3.2 图片管理：独立 Tab + 4:3 缩略图

- 图片独立成 Tab，不再占用主信息区。
- 缩略图统一 **4:3**，自适应网格（最小 180px），列表自适应填充。
- 悬停显示操作层：**预览 / 设为主图 / 重命名 / 删除**（图标按钮 + tooltip）；主图左上角「主图」角标。
- **移除顶部「图片命名」输入框**：命名归属到单张图片的「重命名」弹窗，弹窗内显示该图缩略图与原文件名。
- 上传按钮保留在 Tab 内，上传后提示「可在图片上重命名」。

### 3.3 历史价格：从记录升级为可比较数据

表格列：**服务项目 / 历史报价（¥金额+单位）/ 报价日期 / 有效期至 / 状态 / 备注 / 操作**。

- 报价日期为空时回退显示该条记录的创建日期。
- 有效期为空显示「长期有效」；已过今天显示「已过期」（灰），未过期显示「有效」（绿）。
- 顶部摘要：「共 N 条报价，M 条在有效期内」。
- 维护弹窗支持逐行填写**自定义服务项目、报价、单位、报价日期、有效期至、备注**，并做「有效期不得早于报价日期」校验。
- 保留全量替换语义（保存即整体覆盖），与既有实现一致。

### 3.4 服务评价：先看历史，再新增

- 默认展示：综合评分（大号数字 + 星级）、评价条数、**5→1 星分布条形图**、历史评价列表（头像、姓名、星级、时间、内容）。
- 评分输入区从页面移除，改为右上角**「新增评价」按钮 + 弹窗**，只在用户主动评价时出现。
- **评价对全员开放（2026-11-09 补充，1.0.37.22）**：任何登录用户都可评价，与供应商维护权限解耦。原实现把入口挂在 `supplier:manage`（仅 ADMIN），导致员工/审批人/项目负责人看不到按钮且接口 403，属功能退化，本次恢复并新增独立权限码 `supplier:review`。
- 0 条评价时，空态内提供**「写第一条评价」**按钮，避免只剩一句说明而无入口。

### 3.5 同城供应商：保留特色，降低噪音

- 默认展示**全部同城供应商**（不再默认展开多行彩色标签）。
- 用**单个类型下拉框**替代多行彩色筛选标签（含「全部类型」）。
- 每项显示**完整名称**（不截断，必要时换行）与类型，已绑定供应商带「已绑定」标记。
- **当前档案从列表中排除**，侧栏底部注明「已排除当前档案」。
- 点击供应商切换详情：**保留当前 Tab、搜索词与类型筛选**；顶部返回按钮优先 `router.back()`，配合列表页查询状态入 URL，可回到原来的筛选与页码。

## 4. 数据变更

| 表 | 变更 | 说明 |
|----|------|------|
| `supplier_price_item` | 新增 `quote_date DATE NULL`、`valid_until DATE NULL` | 幂等迁移，仅新增可空列；NULL 表示未填写 / 长期有效，旧数据与旧代码均兼容 |

服务项目（`item_name`）与计费单位（`unit`）为既有字段，无需新增；酒店按间夜、打印店按张/批次等差异通过自由填写 `unit` 表达。

## 5. 范围说明

- 不改供应商列表、类型管理、绑定规则、权限码与后端鉴权。
- 不引入「合作状态」字段（上一版已移除状态徽标）。
- 同一服务项目多次报价仍是**覆盖**而非追加（沿用全量替换语义），若后续要留价格曲线需单独设计历史表，本期不做。

## 6. 验收要点

1. 基本资料三组可见，档案信息默认折叠、可展开。
2. 电话/微信点击复制成功并有提示；http 环境同样可用。
3. 图片 Tab 缩略图为 4:3，悬停出现四个操作，重命名弹窗显示对应图片。
4. 历史价格表出现报价日期与有效期；过期数据显示「已过期」；保存时有效期早于报价日期被拦截。
5. 评价 Tab 默认显示统计与列表，新增评价走弹窗。
6. 同城侧栏为单下拉筛选、名称完整、当前供应商不在列表内；切换后 Tab 与筛选条件不丢；返回列表能还原筛选与页码。
