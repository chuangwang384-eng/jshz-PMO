# 个人工作台可编辑布局需求

日期 2026-11-06 · 待评审

适用于 [个人工作台产品需求](2026-11-02-个人工作台-需求文档.md) 的布局专项。本期改造工作台的卡片容器与布局编辑流程，沿用原需求中的待办、项目预警、搜索和事项处理规则。

## 现状与目标

工作台现有编辑区支持原生拖动重排与按钮调节列宽。保存值只有卡片标识、数组顺序和宽度，普通页面以 CSS Grid 重新排列，无法保存二维位置和高度。用户需要直接操作真实卡片，并在保存后看到刚才编辑的布局。

参考 Grafana 的面板移动与缩放方式，工作台编辑采用「进入编辑 → 在原位调整 → 保存或取消」的流程。产品参考见 [Grafana 面板说明](https://github.com/grafana/grafana/blob/main/docs/sources/visualizations/panels-visualizations/panel-overview/index.md)。

## 交互规则

| 场景 | 预期 |
| --- | --- |
| 首次进入或恢复默认 | 默认首屏优先显示有权限的待处理事项和到期风险，随后是项目、收藏和公告。用户可重新排列默认卡片。 |
| 进入编辑 | 原位显示真实模块及当前布局，显示拖动手柄、右下角缩放手柄、保存、取消、恢复默认和添加模块。默认浏览模式可正常点链接、滚动卡片内容和处理事项。 |
| 拖动位置 | 拖卡片手柄改变列和行，显示网格及目标占位。卡片吸附网格，允许保留空位。拖到其他卡片时显示受影响卡片的位置。无法放置时恢复到本次操作前的位置。 |
| 拖动大小 | 拖右下角手柄改变宽和高，遵循卡片最小尺寸和画布边界。模块内容可滚动，缩放过程中保留阅读与操作空间。移动或缩放完成后可用 Esc 退出未提交的当前操作，或通过取消放弃本次布局编辑。 |
| 键盘操作 | 手柄可聚焦。提供方向移动、宽度和高度增减的按钮或快捷键，遵循相同碰撞与尺寸规则。显示操作结果并保持焦点。 |
| 管理卡片 | 通过模块目录添加，通过卡片操作移除。同一卡片最多出现一次。移除只影响布局。允许清空，空状态提供添加模块和恢复默认入口。 |
| 保存、取消与错误 | 保存后在相同桌面网格下位置和宽高与编辑一致，刷新或重新登录仍可见。取消恢复上次保存状态，有改动时离开页面先提示。恢复默认先作用于编辑预览，保存后才生效。保存失败保留编辑内容并允许重试。遇到另一窗口已经保存时显示冲突并允许重新加载最新布局。 |
| 窄屏 | 建议画布可用宽度小于 900 CSS 像素时单列浏览，按桌面布局从上到下、同排从左到右显示。布局编辑入口提示切换到宽屏，窄屏浏览和调整窗口尺寸均不写入桌面布局。 |
| 账号和权限 | 布局按账号保存。同一账号可跨浏览器使用保存布局。模块权限沿用现有规则，撤权后卡片和入口消失，业务接口继续校验权限。 |

建议本期固定一套桌面布局、采用 12 列网格及显式保存。窄屏独立布局、公共模板、跨账号分享留作后续独立需求。

## 验收条件

1. 真实 Edge 中使用鼠标把卡片移到另一列和另一行，拖动手柄同时改变宽高。编辑预览、保存后、刷新后及重新登录后，相同画布宽度下网格几何一致。
2. 可重复验证碰撞、保留空位、越界与最小尺寸。卡片内容滚动、点击事项和拖拽手柄互不干扰。键盘能独立完成移动、缩放和保存。
3. 添加、移除、清空、恢复默认、取消、网络失败、重新加载和多窗口冲突均按上表表现。切换窄屏后回到桌面，已保存坐标保持一致。
4. 新账号按权限显示默认首屏。既有布局在升级后保留可辨认的卡片和宽度。无权卡片不出现在画布或模块目录中，不同账号的保存结果相互隔离。
5. 使用实际构建产物验证登录后首屏、返回工作台和待办处理闭环。工作台渲染崩溃、空白或保存后位置尺寸变化均视为发布阻断。
