# 个人工作台信息密度优化需求

日期 2026-11-07 · 状态：已评审（Owner 决策确认） · 版本 v1.1

适用于 [个人工作台产品需求](2026-11-02-个人工作台-需求文档.md) 与 [可编辑布局专项](2026-11-06-个人工作台可编辑布局-需求文档.md) 的信息密度与视觉专项。本期只调整工作台的**展示层**，不改变现有的布局编辑逻辑、卡片目录、权限过滤和持久化结构。

## 1. 背景与问题

1.0.34.1 上线后按负责人反馈，工作台具备模块化结构与信息分区，但以"高效、克制、高信息密度"的标准衡量存在以下问题（均已对照 2026-11-07 线上截图与代码核实）：

| # | 问题 | 现状事实 | 来源 |
| --- | --- | --- | --- |
| 1 | 头部垂直空间过大 | "问候语+副标题+日期+刷新按钮+搜索+快捷入口"纵向堆叠，首屏露出核心卡片过少 | 线上截图 |
| 2 | KPI 数字卡片视觉噪音 | 四张统计卡占整行，非零状态背景色（浅红/浅黄）饱和度偏高；数字为 0 时与有内容卡片视觉权重相同；副标题与标题语义重复 | 线上截图 |
| 3 | 列表信息未结构化 | 「我的项目」每行为连续一行文字（阶段 · 负责人 · 结束日期 · 最近推进），无法竖向对齐快速扫读 | DashboardView.vue 模板 |
| 4 | 原始 ISO 时间戳直接展示 | 「最近推进」渲染后端原文 `2026-11-02T15:51:07`，未经格式化 | DashboardView.vue 渲染 `lastPhaseChange.time` 原文 |
| 5 | 风险呈现不够直观 | 「按到期风险排序」但风险仅以小标签显示，逾期与临期在列表中不够醒目 | 线上截图 |
| 6 | 颜色饱和度偏高 | 卡片浅红/浅黄背景在纯白页面下刺眼 | 线上截图 |
| 7 | 视觉层级 | 问候语字号最大，抢了业务数据的焦点 | 线上截图 |

## 2. 目标与非目标

**目标**：降低空状态之外的无用信息视觉噪音，让列表可扫读、时间可读、重要风险一眼可见。

**非目标（本期明确不做，Owner 已确认）**：
- **不做空面板折叠/合并**：面板数据为 0 时的展示形态保持现状。
- **不做内联审批操作**（原 P2-8）：涉及后端接口复用与审计要求，不纳入本期。
- **不做 Ctrl+K 命令面板**（原 P2-9）：不纳入本期。
- 不改变布局编辑与展示逻辑：12 列网格、编辑模式（拖动/缩放/保存/取消/恢复默认）、`CARD_CATALOG`、每用户持久化（`user_dashboard_layout`）、权限与能力过滤全部保持现状。
- 不改任何后端接口契约与数据结构；所有格式化在前端完成。
- 不改造左侧边栏（系统级导航已在侧边栏，现状满足）。
- 不新增或删除任何卡片类型，不改变默认权限规则。

## 3. 需求范围

### 3.1 头部压缩

1. 问候区高度压缩：问候语字号下调（与正文标题同级，约 20px），不再占据页面最大视觉权重；副标题与之平齐。
2. 日期与「刷新工作台」按钮收至问候区右侧同一行。
3. 全局搜索与快捷入口保持现有位置与行为不变。

### 3.2 KPI 卡降噪

1. 统计卡改为"标题 + 数字"紧凑形态，删除与标题语义重复的副标题（如标题已含"待我审批"则不再显示"待处理"）。
2. 数值为 0 时使用极淡样式（近白底/细描边），与非 0 状态区分。
3. 仅异常且非 0 的数值（已逾期项目 > 0）保留红色高亮；其余非 0 数值不做彩色底。

### 3.3 我的项目列表结构化

1. 行内改为对齐网格：项目名（含风险标签）为主列，阶段/负责人/结束日期/最近推进为对齐的属性列，不再用"·"串联长句。
2. 风险视觉强化：风险标签沿用现有 `warning` 字段映射（逾期=danger、临期=warning）；逾期行附加行级强调（如 2px 顶边线），不新增颜色语义。
3. 「我的角色」「详情 →」入口保留。

### 3.4 时间格式化

1. 列表中的时刻统一格式化为 `M月D日 HH:mm`（跨年附年份）；项目结束日期等业务日期保持 `YYYY-MM-DD`。
2. 页面任何位置不允许出现原始 ISO 字符串（`2026-11-02T15:51:07` 类）。

### 3.5 颜色降噪

1. 卡片浅红/浅黄背景改为更淡的底色，或仅顶部彩色边线区分状态。
2. 页面内状态色统一通过 CSS 变量管理，hover/焦点样式不变。

## 4. 交互规则

| 场景 | 预期 |
| --- | --- |
| 空数据面板 | 展示形态保持现状（"暂无…"文案占位），不做折叠或合并 |
| 编辑模式 | 拖动/缩放/保存行为与现状一致，卡片完整显示 |
| 窄屏（<900px） | 沿用现状单列；KPI 卡与列表行自适应 |
| 时间展示 | 时刻 `M月D日 HH:mm`（跨年附年份）；业务日期 `YYYY-MM-DD` |
| 权限 | 所有卡片、入口沿用现有 `perm`/`cap` 规则，无新增权限 |

## 5. 验收条件

1. 头部：问候区为一行，日期与刷新按钮右对齐；问候语字号不大于板块标题；首屏露出核心卡片数量较改造前增加。
2. KPI 卡：0 值无彩色底、无重复副标题；已逾期 > 0 时保持红色高亮。
3. 「我的项目」行内属性竖向对齐；逾期/临期标签颜色正确；无权限卡片不出现在任何形态。
4. 页面中所有时间均为格式化文本，模板中无裸 ISO 输出（`2026-10-28 02T15:51:07` 类问题不复现）。
5. 空面板形态与改造前一致（截图对比）。
6. 真实 Edge + 构建产物验证：登录首屏、返回工作台、刷新、拖拽编辑保存闭环回归通过；已保存自定义布局升级后完好。
