# 工作台导航与快捷访问整合需求

日期 2026-11-07 · 状态：待评审 · 关联：[个人工作台产品需求](2026-11-02-个人工作台-需求文档.md) / [可编辑布局专项](2026-11-06-个人工作台可编辑布局-需求文档.md)

本专项整合工作台顶部的搜索与快捷入口，改造全局顶部导航右侧的用户区，并统一工作台模块的设计规范。概念图为布局示意，非现有系统截图。

## 1. 现状事实（已核实，2026-11-07）

| 项 | 现状 | 位置 |
| --- | --- | --- |
| 顶部导航右侧 | 铃铛（MessageDrawerBell）+ 用户名文本 + 「退出登录」常驻链接按钮 | `App.vue` `.user-area`（**全局组件，影响所有页面**） |
| 全局搜索 | 独立模块，"全局搜索"标题 + 输入框 + 搜索按钮；无键盘快捷键唤起 | `GlobalSearchBar.vue`（防抖 300ms、分组结果、键盘上下选择已具备） |
| 快捷入口 | 8 个固定文本按钮（知识星球/项目管理/专家库/客户信息/供应商/我的申请/公告/通讯录），右侧带 ↗ 箭头，按能力（capabilities）过滤，**全员相同、不可配置** | `DashboardView.vue` `entries` 硬编码 |
| 纵向占用 | 顶部导航 → 问候区 → 全局搜索 → 快捷入口四个独立区块堆叠 | 工作台页 |

## 2. 目标与非目标

**目标**：减少首屏纵向占用；导航与操作层级更清晰；搜索与快捷访问整合为一个模块；快捷访问支持个性化；建立工作台统一设计规范。

**非目标（本期不做）**：
- 不改工作台卡片的编辑布局逻辑（12 列网格、拖拽编辑、`user_dashboard_layout` 持久化保持现状）。
- 不改搜索后端接口（`globalSearch` 的模块、分组、权限过滤维持现状）。
- 不做左侧边栏（Sidebar）改造。
- 设计规范本期仅应用于工作台模块与顶部导航，不批量刷新其他页面。

## 3. 需求范围

### P0 顶部导航右侧改造（全局）

1. 现状「铃铛 | 用户名 | 退出登录」改为「通知图标 | 用户头像 + 下拉菜单」。
2. 头像默认取用户名首字（如"王"）+ 底色，点击展开下拉菜单，含：**个人中心**（指向现有 `/profile`）、**账号设置**（指向现有资料/改密入口，具体路由实施时核实）、**退出登录**。
3. 「退出登录」从常驻导航移除，仅出现在下拉菜单内；退出确认弹窗（`ElMessageBox.confirm`）行为保持不变。
4. 通知图标点击行为与现状一致（打开消息抽屉）。

### P0 搜索与快捷访问整合为一个模块

1. 工作台页将「全局搜索」与「快捷入口」合并为一张卡片：上行为搜索输入框（带 Ctrl K 提示徽标），下行为快捷访问行；删除两者之间的独立标题与分隔留白。
2. 整合后首屏纵向占用较现状减少一个区块高度。

### P1 快捷访问组件化与个性化

1. 形态：改为"图标 + 名称"紧凑组件，去除斜向箭头；默认最多展示 **6 个**，其余收进「更多」下拉。
2. **个性化配置**：员工可自行增删、排序自己的快捷访问；默认值 = 现有能力过滤后的入口顺序；配置按账号保存、跨浏览器生效。
3. 配置入口：快捷访问行右侧「编辑」按钮，编辑态支持拖动排序与增删，保存/取消/恢复默认。
4. 权限约束：可选入口集合 = 现有能力（capabilities）过滤结果；撤权后对应入口自动从用户配置与默认展示中消失。
5. 持久化：**新增按账号保存的快捷访问配置**（后端表 + GET/PUT 接口，沿用 `user_dashboard_layout` 的实现与幂等迁移模式）。

### P1 全局搜索升级为 Command Search

1. 全局快捷键 **Ctrl K / ⌘K** 唤起/聚焦搜索框（工作台页及全局页头均可触发，焦点自动落输入框）；Esc 关闭结果面板。
2. 输入框右侧显示 `Ctrl K` 提示徽标；去除独立「搜索」按钮（回车即搜）。
3. 搜索行为、结果分组、权限过滤与现状一致；本期不新增"跳转去审批/新建项目"等动作命令（留作后续评估）。

### P2 设计规范统一（工作台模块范围）

按以下规范应用样式（仅工作台模块 + 顶部导航，不动其他页面）：

| 设计元素 | 规范 |
| --- | --- |
| 主色 | `#2563EB` |
| 页面背景 | `#F8FAFC` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#0F172A` |
| 次级文字 | `#64748B` |
| 边框 | `#E2E8F0` |
| 圆角 | 8～12px |
| 顶部导航高度 | 60～64px |
| 页面左右间距 | 24～32px |
| 图标 | Lucide Icons（见决策点 3） |
| 组件风格 | 轻边框、低阴影、明确交互状态 |

颜色通过 CSS 变量集中定义，避免散落硬编码。

## 4. 交互规则

| 场景 | 预期 |
| --- | --- |
| 任意页面按 Ctrl K | 聚焦工作台搜索框（工作台页）；其他页面行为见决策点 2 |
| 点击头像 | 展开下拉（个人中心/账号设置/退出登录），点击外部或 Esc 关闭 |
| 快捷访问 ≤ 6 个 | 全部平铺，无「更多」 |
| 快捷访问 > 6 个 | 平铺前 6 个 + 「更多 ▾」下拉收纳其余 |
| 编辑快捷访问 | 进入编辑态：拖动排序、添加（来自能力过滤后的候选）、移除、恢复默认；保存失败保留编辑内容 |
| 账号被撤权 | 对应入口从默认与个性化配置中同时消失，业务接口权限校验不变 |
| 退出登录 | 仅下拉菜单内可触发，二次确认后登出并跳转登录页 |
| 窄屏（<900px） | 快捷访问换行或横滚；顶部导航元素不换行溢出 |

## 5. 验收条件

1. 顶部导航右侧为「通知图标 + 头像下拉」，下拉三项均可用；「退出登录」不再常驻显示；登出流程与现状等价（确认弹窗 → 清理会话 → 跳登录页）。
2. 工作台首屏：搜索与快捷访问在一张卡片内；Ctrl K 聚焦搜索并出现提示徽标；纵向高度较改造前减少。
3. 快捷访问显示图标 + 名称、无箭头；>6 个时「更多」收纳；编辑态可拖动排序、增删、恢复默认并保存成功。
4. 换账号登录：各自快捷访问配置互不影响；未配置过的新账号显示默认入口；撤权账号对应入口消失。
5. 工作台与顶部导航符合 §3-P2 色板/圆角/间距规范（抽查 5 处以上）。
6. 真实 Edge + 构建产物验证：登录首屏、Ctrl K 搜索、头像下拉登出、快捷访问编辑保存、刷新后配置还原；既有布局编辑与搜索回归通过。

## 6. 需要负责人决策的事项

1. **头像形态**：本期用"用户名首字 + 底色"占位（不依赖照片存储），还是接入已有专家照片/头像（涉及文件权限与加载策略）？建议本期用首字占位。
2. **Ctrl K 作用范围**：仅工作台页生效（实现简单），还是注册为全局快捷键（其他页面唤起搜索需搜索组件挂到全局层，改动更大）？建议本期仅工作台页。
3. **图标库**：规范推荐 Lucide Icons，但项目现有依赖为 `@element-plus/icons-vue`。引入 `lucide-vue-next` 为新增依赖；沿用现有库则风格统一、零新依赖。建议本期沿用现有图标库，Lucide 留作后续统一替换。
4. **「更多」与编辑态的样式细节**是否按概念图执行（行内"图标+名称"胶囊样式）。
