# 工作台导航与快捷访问整合需求

日期 2026-11-07 · 状态：已评审（Owner 决策确认） · 版本 v1.1

本专项整合工作台顶部的搜索与快捷入口，为快捷访问提供个性化能力，并统一工作台模块的设计规范。概念图为布局示意，非现有系统截图。

## 1. 现状事实（已核实，2026-11-07）

| 项 | 现状 | 位置 |
| --- | --- | --- |
| 全局搜索 | 独立模块，"全局搜索"标题 + 输入框 + 搜索按钮；无键盘快捷键唤起 | `GlobalSearchBar.vue`（防抖 300ms、分组结果、键盘上下选择已具备） |
| 快捷入口 | 8 个固定文本按钮（知识星球/项目管理/专家库/客户信息/供应商/我的申请/公告/通讯录），右侧带 ↗ 箭头，按能力（capabilities）过滤，**全员相同、不可配置** | `DashboardView.vue` `entries` 硬编码 |
| 纵向占用 | 顶部导航 → 问候区 → 全局搜索 → 快捷入口四个独立区块堆叠 | 工作台页 |

## 2. 目标与非目标

**目标**：减少工作台首屏纵向占用；搜索与快捷访问整合为一个模块；快捷访问支持个性化；建立工作台统一设计规范。

**非目标（本期明确不做，Owner 2026-11-07 决策确认）**：
- **不做顶部导航右侧改造**：App.vue 页头为全局组件，影响所有页面；「通知图标 + 头像下拉（个人中心/账号设置/退出登录）」整体移出本期，留作后续独立需求。铃铛、用户名、退出登录的现有形态保持不变。
- 不改工作台卡片的编辑布局逻辑（12 列网格、拖拽编辑、`user_dashboard_layout` 持久化保持现状）。
- 不改搜索后端接口（`globalSearch` 的模块、分组、权限过滤维持现状）。
- 不做左侧边栏（Sidebar）改造。
- 不引入新图标依赖：沿用现有 `@element-plus/icons-vue`，Lucide Icons 留作后续统一替换。
- 设计规范本期仅应用于工作台模块，不批量刷新其他页面。

## 3. 需求范围

### P0 搜索与快捷访问整合为一个模块

1. 工作台页将「全局搜索」与「快捷入口」合并为一张卡片：上行为搜索输入框（带 Ctrl K 提示徽标），下行为快捷访问行；删除两者之间的独立标题与分隔留白。
2. 整合后首屏纵向占用较现状减少一个区块高度。

### P1 快捷访问组件化与个性化（本期唯一后端变更）

1. 形态：改为"图标 + 名称"紧凑组件，去除斜向箭头；默认最多展示 **6 个**，其余收进「更多」下拉。
2. **个性化配置**：员工可自行增删、排序自己的快捷访问；默认值 = 现有能力过滤后的入口顺序；配置按账号保存、跨浏览器生效。
3. 配置入口：快捷访问行右侧「编辑」按钮，编辑态支持拖动排序与增删，保存/取消/恢复默认。
4. 权限约束：可选入口集合 = 现有能力（capabilities）过滤结果；撤权后对应入口自动从用户配置与默认展示中消失。
5. 持久化：新增按账号保存的快捷访问配置（后端新表 `user_quick_access` + GET/PUT 接口，沿用 `user_dashboard_layout` 的实现与幂等迁移模式）。

### P1 全局搜索升级为 Command Search

1. 快捷键 **Ctrl K / ⌘K** 唤起/聚焦搜索框（**仅工作台页生效**，Owner 已确认；其他页面不注册全局快捷键），焦点自动落输入框；Esc 关闭结果面板。
2. 输入框右侧显示 `Ctrl K` 提示徽标；去除独立「搜索」按钮（回车即搜）。
3. 搜索行为、结果分组、权限过滤与现状一致；本期不新增"跳转去审批/新建项目"等动作命令（留作后续评估）。

| --- | --- | --- |
| 主色 | `#2563EB` | ✓ |

| 卡片背景 | `#FFFFFF` | ✓ |

## 4. 交互规则

| 场景 | 预期 |
| --- | --- |
| 工作台页按 Ctrl K | 聚焦搜索框；其他页面无此快捷键 |
| 快捷访问 ≤ 6 个 | 全部平铺，无「更多」 |
| 快捷访问 > 6 个 | 平铺前 6 个 + 「更多 ▾」下拉收纳其余 |
| 编辑快捷访问 | 进入编辑态：拖动排序、添加（来自能力过滤后的候选）、移除、恢复默认；保存失败保留编辑内容 |
| 账号被撤权 | 对应入口从默认与个性化配置中同时消失，业务接口权限校验不变 |
| 窄屏（<900px） | 快捷访问换行或横滚；顶部导航现有形态不变 |

## 5. 验收条件

1. 工作台首屏：搜索与快捷访问在一张卡片内；Ctrl K 聚焦搜索并出现提示徽标；纵向高度较改造前减少。
2. 快捷访问显示图标 + 名称、无箭头；>6 个时「更多」收纳；编辑态可拖动排序、增删、恢复默认并保存成功；「更多」与编辑态样式按概念图执行。
3. 换账号登录：各自快捷访问配置互不影响；未配置过的新账号显示默认入口；撤权账号对应入口消失。
4. 顶部导航右侧形态与改造前一致（铃铛/用户名/退出登录不动，截图对比）。
5. 工作台模块符合 §3-P2 色板/圆角/间距规范（抽查 5 处以上）。
6. 真实 Edge + 构建产物验证：登录首屏、Ctrl K 搜索、快捷访问编辑保存、刷新后配置还原；既有布局编辑与搜索回归通过。构建必须带 `VITE_DASHBOARD_LAYOUT_V2=true`。

## 6. 已决策事项记录（2026-11-07 Owner 确认）

1. 顶部导航右侧改造（头像下拉）**本期不做**。
2. 快捷访问个性化后端变更（新表+新接口）**确认纳入**。
3. 图标库**沿用现有 `@element-plus/icons-vue`**，Lucide 留作后续统一替换。
4. Ctrl K **仅工作台页生效**。
5. 「更多」与编辑态样式**按概念图执行**。
6. 头像形态（首字占位/照片）随页头改造一并决策，本期不涉及。
