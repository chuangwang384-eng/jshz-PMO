# 供应商详情页 UI 重构设计文档（v1）

| 项 | 内容 |
|---|---|
| 系统 | 景帅会展内部管理系统（jshz-PMO） |
| 模块 | 专家库子系统 · 供应商管理模块 |
| 涉及页面 | 供应商详情页（SupplierDetail.vue） |
| 文档版本 | v1 |

| 面向对象 | 前端 / 后端开发、测试 |

## 1. 概述

### 1.1 目标

对供应商详情页进行三栏化 UI 与信息架构优化：优化信息展示层级、新增右侧同城市供应商快速导航、优化图片管理与历史价格视觉呈现、降低留白提高信息密度，保持 OA 风格一致。

### 1.2 范围

| 范围 | 说明 |
|---|---|
| 在本轮 | 详情页前端布局重构、同城导航、图片管理视觉优化、历史价格视觉优化、评价模块完整保留、小屏折叠 |
| 不在本轮 | 合作记录模块（暂不做）、图片手动排序、后端接口新增、数据库结构变更、权限模型变更 |

### 1.3 决策摘要表

| 编号 | 决策点 | 结论 | 依据 / 影响 |
|---|---|---|---|
| D1 | 同城导航范围 | 同城市全部类型；酒店/打印店详情页已绑定供应商置顶（带「已绑定」标记）；跨城绑定不混入 | 绑定时已做同城限制 |
| D2 | 同城数据获取 | 复用 `GET /api/supplier/list`（cityId 过滤），size=200，超出按总数提示 | 不新增接口 |
| D3 | 图片管理 | 不做手动排序，纯视觉优化（上传自增顺序、主图置顶） | 避免新增后端能力 |
| D4 | 历史价格 | 标题改「历史价格」，保留 PUT /prices 全量替换；按钮统一「新增价格」，全页面不用"行价" | 文案与模块语义统一 |
| D5 | 图片删除 | 悬停显示（与现有 hover 操作层一致） | 弱化删除、保留快捷操作 |
| D6 | 顶部操作区 | 不新增"合作状态"字段；展示类型标签 + 所在城市 + 建档时间 | 不扩表 |
| D7 | 合作记录 | 本轮不做 | 中间栏第三区块改为评价 |
| D8 | 评价模块 | 完整保留（评分汇总 + 评价列表 + 提交表单），放中间栏第三区块 | 保留既有能力 |
| D9 | 三栏宽度 | 左 340px / 中自适应 / 右 280px | 信息密度与可读性平衡 |
| D10 | 缩略图 | 统一 160×120，名称在下方一行省略 | 视觉统一 |
| D11 | 右侧搜索 | 前端本地过滤，输入即过滤 | 不新增接口 |
| D12 | 小屏适配 | <1200px 右栏折叠为顶部可展开按钮（抽屉 + 遮罩） | 响应式兜底 |

## 2. 现状技术核查

### 2.1 前端组件

| 文件 | 说明 |
|---|---|
| `frontend/src/views/supplier/SupplierDetail.vue` | 详情页主体（702 行单文件），单列全宽堆叠 5 个 el-card |

| `frontend/src/api/supplier.js` | 供应商接口封装 |
| `frontend/src/utils/supplier.js` | 供应商工具函数 |
| `frontend/src/utils/imageCompress.js` | 图片上传压缩工具 |
| `frontend/src/directives/permission.js` | 权限指令（v-permission） |

### 2.2 后端接口清单（Controller 基址 `/api/supplier`）

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/api/supplier/list` | 分页查询，已支持 typeId + cityId 过滤；返回含 imageList / mainImage / avgStars / reviewCount | 登录即可 |
| GET | `/api/supplier/{id}` | 详情，返回 `{supplier, priceItems, reviews, bindings}`，**不含同城列表** | 登录即可 |
| GET | `/api/supplier/{id}/images` | 图片列表 | 登录即可 |
| POST | `/api/supplier/{id}/images` | 上传图片（≤20 张 / 单张 ≤8MB / 累计 ≤100MB / 首图自动主图 / 自动压缩） | supplier:manage |
| PUT | `/api/supplier/{id}/images/main` | 设置主图 | supplier:manage |
| PUT | `/api/supplier/{id}/images/name` | 图片改名 | supplier:manage |
| DELETE | `/api/supplier/{id}/images/{imageId}` | 删除图片 | supplier:manage |
| PUT | `/api/supplier/{id}/prices` | 行价全量替换 | supplier:manage |
| POST | `/api/supplier/{id}/reviews` | 新增评价 | supplier:manage |
| GET | `/api/supplier/bindings/cross-city` | 跨城绑定清单 | 登录即可 |
| POST / DELETE | `/api/supplier/bindings` | 新增 / 解除绑定 | supplier:binding |
| GET | `/api/supplier/types`、`/api/supplier/cities` | 类型 / 城市字典 | 登录即可 |

### 2.3 数据表结构

| 表 | 关键字段 / 说明 |
|---|---|
| `supplier` | 供应商主表，含 `city_id` 外键（关联 `supplier_city.id`），一供应商一城市 |
| `supplier_image` | 图片表，含 `is_main`（0/1 主图标记）、`sort_order`（上传自增排序，无手动排序接口） |
| `supplier_price_item` | 历史价格条目表 |
| `supplier_review` | 评价表 |
| `supplier_hotel_print_rel` | 酒店/打印店绑定关系表，含 `peer_city_id`（跨城标记） |
| `supplier_type` / `supplier_city` | 类型 / 城市字典，固定只读 |

### 2.4 权限现状

| 项 | 现状 |
|---|---|
| 权限过滤机制 | `DbPermissionFilter` 按 method + AntPath 匹配校验；未命中放行 |
| 最新生效脚本 | `20261101_open_supplier_permission.sql` |
| `supplier:manage` | 仅 ADMIN（编辑 / 删除 / 图片 / 价格 / 评价 / 批量解绑） |
| `supplier:create` / `supplier:binding` | 全部非超管角色 |
| GET 类接口 | 无 permission 规则，登录即可放行 |
| SUPER_ADMIN | `PermissionService` 代码内强制全权（不依赖 role_permission） |
| ⚠️ 注意 | **代码注释与权限规则现状脱节**（Controller / api.js / 列表页副标题仍写"全员可直接维护"，实际已收紧）；权限判断以最新生效脚本为准，不得依据代码注释 |

## 3. 前端布局设计

### 3.1 栅格方案

| 区域 | 布局方案 |
|---|---|
| 左栏 | 固定宽 340px：供应商基本信息，紧凑两列（名称/类型/城市/地址/联系人/电话/微信/描述/评分/建档人/建档时间） |
| 中栏 | `flex: 1` 自适应：图片管理 / 历史价格 / 评价 三个卡片区块，纵向堆叠 |
| 右栏 | 固定宽 280px：同城市供应商导航，独立布局 |
| 整体 | 三栏容器禁止横向滚动；卡片统一圆角 8px、边框 `#ebeef5`、间距 16px |

结构示意：

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶部操作区：返回链接 · 供应商名称（大字） · 类型标签 · 城市 · 建档时间 · 编辑 · 删除 │
├───────────────┬─────────────────────────────────┬───────────┤
│ 左栏 340px    │ 中栏（flex:1）                    │ 右栏 280px │
│ 基本信息      │ 图片管理                          │ 同城市导航 │
│ （紧凑两列）  │ 历史价格                          │           │
│               │ 评价                              │           │
└───────────────┴─────────────────────────────────┴───────────┘
```

### 3.2 顶部操作区

- 布局：单行工具条，左对齐返回链接，中间供应商名称（大字），右侧依次类型标签、所在城市、建档时间、编辑按钮、删除按钮。
- 字段来源：`GET /api/supplier/{id}` 返回的 supplier 对象（name / typeName / cityName / createTime）。

### 3.3 小屏折叠交互

- 断点：`<1200px`。
- 行为：右栏隐藏，顶部操作区出现「同城市供应商」展开按钮；点击弹出抽屉（遮罩 + 右侧面板，复用桌面端列表内容）。
- 交互：抽屉可关闭（点遮罩或关闭按钮）；进入抽屉后点击供应商名称仍走详情页路由。

## 4. 同城市导航设计

### 4.1 数据来源与请求

| 项 | 设计 |
|---|---|
| 接口 | 复用 `GET /api/supplier/list` |
| 请求参数 | `cityId`（当前供应商城市）+ `size=200` |
| 超出处理 | 列表接口返回总数 > 200 时，按总数提示（如「共 N 家，仅展示前 200 家」） |
| 补充请求 | 当前供应商详情 `GET /{id}` 不含同城列表，导航数据需单独请求 list 接口 |

### 4.2 前端本地过滤

- 搜索框输入即过滤：按供应商名称前端本地过滤（`includes` 匹配，忽略大小写）。
- 不触发后端请求，无新增接口。

### 4.3 列表排序逻辑

```text
1. 排除当前供应商（id 相同的不展示）
2. 已绑定供应商置顶（仅酒店/打印店场景，且仅同城列表内；带蓝色「已绑定」标记）
3. 其余按名称排序
```

- 排序依据：`supplier_hotel_print_rel` 绑定关系（bindings）；跨城绑定不进入同城列表（绑定时已同城限制）。

### 4.4 状态与空状态分支

| 分支 | 展示 |
|---|---|
| 城市信息缺失 | 「该供应商暂无城市信息，无法展示同城市供应商」 |
| 同城无其他供应商 | 空列表提示（同城市仅此一家） |
| 搜索无结果 | 本地过滤后空结果提示 |

### 4.5 点击跳转

- 列表项点击 → 路由跳转 `/supplier/{id}`，进入对应供应商详情页。
- 当前供应商高亮：主色浅底 + 左边框。

## 6. 历史价格设计

### 6.1 表格列定义

| 列 | 说明 |
|---|---|
| 品名 | 文本 |
| 价格 | 加粗、右对齐，突出显示 |
| 单位 | 文本 |
| 备注 | 文本 |
| 操作 | 「编辑」按钮（打开弹窗） |

### 6.2 760px 弹窗结构

- 标题「编辑价格」（原"编辑历史价格"）。
- 动态行表格：品名 / 价格 / 单位 / 备注；支持增行、删行。
- 提示文案：「保存后将整体替换现有价格数据」。
- 操作：保存 / 取消。

### 6.3 全量替换语义

- 新增与编辑均打开同一弹窗，保存时调用 `PUT /api/supplier/{id}/prices` 全量替换现有价格数据。
- 保留既有接口语义，不做单条价格接口。

### 6.4 空状态

- 无数据时缩小空状态区域：一行「暂无价格数据」+「新增价格」按钮。

## 7. 评价模块设计

### 7.1 评分汇总区

- 展示：平均分（金色星条）+ 评价条数。
- 数据来源：详情接口返回的 `avgStars` / `reviewCount`。

### 7.2 评价列表

| 字段 | 说明 |
|---|---|
| 星级 | 金色迷你星条（★/☆） |
| 评价内容 | 正文 |
| 评价人 | 用户名 |
| 评价时间 | 时间文本 |
| 空状态 | 「暂无评价」 |

- 排布：紧凑列表，一条评价一行信息头（星级 + 评价人 + 时间）+ 内容正文。

### 7.3 提交表单

- 星级选择：点击选星（1~5）。
- 评价内容：输入框，限 500 字。
- 提交按钮：调用 `POST /api/supplier/{id}/reviews`。

### 7.4 提交后刷新流程

```text
提交成功 → 重置表单（清空星级与内容）→ 重新拉取详情接口（或局部刷新评价数据）
         → 更新评分汇总与评价列表
```
