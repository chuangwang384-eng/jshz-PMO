## 三、状态机与流转设计

```
待审(0) ──通过──────→ 通过(1) [终态]
  │  ├──驳回──────→ 驳回(2) [终态]
  │  ├──撤回──────→ 撤回(3) [终态]
  │  └──退回修改──→ 退回修改(4) ──员工修改后重新提交──→ 待审(0) ──→ 回到原审批人(按 approver_snapshot)
```

- 退回修改为**非终态**，仅待审（status=0）可操作；重新提交后回待审（status=0），原单 ID 不变。
- 重新提交时重置转办/加签信息（current_assignee、extra_approver 置空/重置），避免被退回单残留转办人导致无人可审。
- 审批人判定：**优先使用 application.approver_snapshot（进行中单）**；新申请提交时从 approval_config_user 生成快照。
