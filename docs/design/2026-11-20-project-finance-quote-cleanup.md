# 会前财务资料与报价归档设计

- ProjectFinanceForm 根据项目类型选择字段。可编辑默认值仅补缺，已有保存值包含主动清空的空字符串。旧平台简称中明确对应三个新选项的值做显示转换，其他无效选项需重新选择。
- GET/PUT /api/project/{id}/stage-form 延续现有契约，会前财务阶段从项目主数据重算日期、名称及现有负责人字段，后端覆盖客户端同名值。未保存表单由页面实时显示项目值。
- PUT /api/project/{id}/meeting-budget 的 confirm=true 和 POST /api/project/{id}/meeting-budget/confirm 共用自动归档规则。确认、项目金额更新、归档的文件及版本记录在同一事务内完成。预算锁串行化同项目确认，按报价业务字段生成稳定的幂等键，复用已有唯一索引和回滚时删除临时归档文件的逻辑。归档复用现行 QUOTE 导出格式，不写成本单。
- ProjectDetail 在预算保存后刷新项目文件，按文件 ID 倒序展示最近十条，既有预览、下载继续使用。一轮确认失败由同一事务回滚，避免仅确认而未挂载文件。
- 旧页面区块及专用前端封装删除。项目编辑与阶段业务保留。共享后台的历史审批、报表、旧配置推进、数据访问继续沿用。已配置旧必填模板仍可展示完成状态，项目管理员继续按现有配置流程处理其要求。
- 没有新增表或字段。1.0.98 的项目类型与阶段表单是本版本前置基线。旧版本回滚可继续读取本版本生成的报价和已保存的财务表单。
