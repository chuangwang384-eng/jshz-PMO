## 2. 后端设计

### 2.1 列表筛选参数（全部可选，组合生效）

`GET /api/experts?keyword=&page=&size=` 新增：

| 参数 | 类型 | 后端处理 |
| --- | --- | --- |
| `unit` | string | `unit = ?` 精确（下拉选定值） |
| `department` | string | `department = ?` 精确 |
| `titles` | CSV 多选 | `title IN (?)` |
| `photo` | `uploaded` / `missing` | `photo IS NOT NULL AND photo != ''` / 取反 |
| `updatedFrom` / `updatedTo` | `yyyy-MM-dd` | `update_time >= from 00:00` / `< to+1d` |

- `pageList` 签名扩展为筛选对象；SQL 用现有 JdbcTemplate 动态拼接（与 keyword 逻辑同文件同风格），参数化查询防注入。
- 兼容：旧前端不传新参数时行为与现状完全一致。

### 2.2 字典接口

`GET /api/experts/filters`（登录即可，同列表权限）：返回

```json
{ "units": ["..."], "departments": ["..."], "titles": ["..."] }
```

`SELECT DISTINCT` + 空值过滤 + 按数量降序；前端缓存于会话（打开高级筛选时拉取一次）。

## 3. 前端设计

### 3.1 三层结构

```
┌ 第一层 搜索筛选区 ────────────────────────────────┐
│ [🔍 统一搜索 480px] [高级筛选(徽标N)] [重置] [单位查询外链] │
│ （展开：单位▾ 科室▾ 职称多选▾ 照片状态 更新时间范围）      │
├ 第二层 工具行 ────────────────────────────────────┤
│ 专家档案 · 共 N 人        显示方式 [卡片⠿ | 列表☰]      │
├ 第三层 内容区 ────────────────────────────────────┤
│ 卡片网格 / 表格（共用分页）                             │
└──────────────────────────────────────────────────┘
```

### 3.2 紧凑卡片

- 头像 128px → 80px（`PhotoImage :width/:height=80`），照片区与文字区改为横向布局：左头像右文字，卡片高度约 200px。
- 保留：勾选框、更新时间/修改人/下载次数元信息、点击进详情。

### 3.3 列表视图

- `el-table`：勾选列（`!canExport`）/ 头像缩略 / 姓名 / 单位 / 科室 / 职称 / 联系方式 / 更新时间 / 操作（查看详情链接）。
- 勾选状态走同一 `selectedIds`/`selectedExperts` 集合，跨视图跨页共用。
- `viewMode = ref('card')`，切换仅控制渲染分支，不重新请求。

### 3.4 高级筛选

- 折叠面板（`el-collapse-transition` + 自定义行），展开时拉取字典接口（会话缓存）。
- 筛选状态对象 `filters = reactive({ unit:'', department:'', titles:[], photo:'', updatedRange:[] })`；任一变更 → `page=1` + `fetchList()`；已启用条件数徽标显示在「高级筛选」按钮上。
- 一键重置：`Object.assign(filters, 初始值)` + 重新加载。

### 3.5 导出与批量栏

- 工具行右侧「导出 ▾」下拉：有 `expert:export` → 全量 Excel/全量 ZIP；无权限 → 选中 Excel/选中 ZIP（未勾选置灰）。
- `canExport` 权限用户勾选专家后，悬浮批量栏同样出现（选中导出能力对管理员同样有用；若 Owner 认为管理员不需要，砍掉即可）。
- 悬浮批量栏：`position:fixed; bottom:24px` 居中胶囊：已选 N 位 | 下载 Excel | 下载 ZIP | 清空。

## 5. 风险与兼容

- 筛选参数全部可选 → 旧前端/旧调用零影响。
- 字典接口 DISTINCT 全表查询在当前数据量（数百级专家）下性能可接受；数据量增长后再考虑缓存。
- `ExpertList.vue` 改动量大（约 1367 行文件重构模板上半部），详情弹窗与审批流逻辑**原样保留**，重构范围严格限定在列表区。
- 省市地区与档案状态字段本期不做（决策点见需求 §5），后续如做需加列迁移。
