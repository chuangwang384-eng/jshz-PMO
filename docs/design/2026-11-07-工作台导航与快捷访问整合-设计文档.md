# 工作台导航与快捷访问整合设计

日期 2026-11-07 · 状态：待评审 · 关联需求：[2026-11-07-工作台导航与快捷访问整合-需求文档](../requirements/2026-11-07-工作台导航与快捷访问整合-需求文档.md)

## 1. 改动边界与影响面

| 组件 | 改动 | 影响范围 |
| --- | --- | --- |
| `frontend/src/App.vue` | `.user-area` 改造：头像下拉（新增 UserMenu 子组件） | **全局所有页面**（最高回归风险点） |
| `frontend/src/components/GlobalSearchBar.vue` | Ctrl K 支持、提示徽标、去独立搜索按钮、可被外部聚焦 | 工作台页 |
| `frontend/src/views/dashboard/DashboardView.vue` | 搜索+快捷访问合并卡片；快捷访问行组件化 | 工作台页 |
| 新组件 `frontend/src/components/QuickAccessBar.vue` | 图标+名称组件、更多下拉、编辑态 | 工作台页 |
| 后端 | 新表 + GET/PUT 接口（快捷访问配置） | 新增，不影响现有接口 |
| 数据库 | 1 张新表迁移脚本（幂等） | 仅加表 |

布局编辑逻辑（`user_dashboard_layout`、12 列网格、编辑模式）与搜索后端接口零改动。

## 2. 顶部导航右侧改造（P0）

### 2.1 UserMenu 子组件

在 `App.vue` 同目录或 `components/` 下新增 `UserMenu.vue`：

- 触发器：圆形头像（36px，背景取主色 `#2563EB` 的浅色阶如 `#DBEAFE`，文字取用户名首字 `auth.username.slice(0,1)`）+ 下拉箭头图标。
- 下拉面板：`el-dropdown`（Element Plus 现有组件，与现有技术栈一致）承载三项：
  - 个人中心 → `router.push('/profile')`
  - 账号设置 → 现有改密/资料入口（实施时以 `ProfileHome.vue` 内实际路由为准；若无独立页面则指向 `/profile` 并高亮资料卡片）
  - 退出登录 → 复用 `App.vue` 现有 `handleLogout`（`ElMessageBox.confirm` 确认 → 清理会话 → 跳登录），通过 `emit('logout')` 调用，**不复制登出逻辑**
- 铃铛 `MessageDrawerBell` 保留原位，样式对齐新规范。
- 删除 `.user-area` 中用户名文本与常驻退出按钮；用户名移入下拉面板顶部展示（头像下加姓名与角色，供确认当前账号）。

### 2.2 权限与安全

- 下拉项按现有路由守卫权限展示；不新增权限点。
- 登出逻辑唯一入口仍是 `handleLogout`，避免两套实现导致会话清理不一致。

## 3. 搜索 + 快捷访问整合卡片（P0/P1）

### 3.1 结构

`DashboardView.vue` 中删除 `<GlobalSearchBar />` 与 `<nav class="quick-links">` 两个独立区块，替换为一张 `.nav-card`：

```
┌─ .nav-card ──────────────────────────────────────────┐
│ 🔍 搜索专家、项目、客户、供应商或知识文档…    [Ctrl K] │  ← GlobalSearchBar（改造后，无边框标题）
│ ────────────────────────────────────────────────────  │
│ 快捷访问 [条目][条目][条目][条目][条目][条目] [更多▾][编辑] │  ← QuickAccessBar
└──────────────────────────────────────────────────────┘
```

- `GlobalSearchBar` 保留全部搜索逻辑（防抖/分组/键盘导航/清空），仅：删 label 标题、输入框样式改为 `#F1F5F9` 底 + 无独立搜索按钮（回车触发）、右侧加 `.kbd-hint`（`Ctrl K`）。
- Ctrl K：`DashboardView.vue` `onMounted` 注册 `document.addEventListener('keydown')`，`event.ctrlKey/metaKey && key==='k'` 时 `preventDefault()` 并调用 GlobalSearchBar 暴露的 `focus()`（`defineExpose`）。组件卸载时移除监听。**仅工作台页生效**（决策点 2）。

### 3.2 QuickAccessBar 组件

```js
// 数据模型（对齐 user_dashboard_layout 的"配置即数据"思路）
QuickAccess = { id: 'page.project', order: 0 }   // 只存卡片标识与顺序，不存标题/图标/路径
```

- **候选集** = `CARD_CATALOG` 中 `page.*` 项（复用现有 `perm`/`cap` 过滤函数 `canShow`），新增入口零代码（改目录即可）。
- 默认顺序 = 现有 `entries` 顺序过滤后取前 6，其余进「更多」。
- 图标：每项固定映射一个现有 `@element-plus/icons-vue` 图标（决策点 3；如后续引入 Lucide 仅改映射表）。
- 「更多 ▾」：`el-dropdown` 列出第 7 项起条目。
- 编辑态：行内按钮进入；候选列表（含未启用项）+ 已启用列表，点击增删、`HTML5 drag&drop` 排序（复用可编辑布局的原生拖拽模式，不引第三方库）；「保存/取消/恢复默认」；有改动离开页面提示（`onBeforeRouteLeave` 已有同类拦截，模式一致）。

## 4. 快捷访问个性化持久化（P1，后端）

### 4.1 数据库（1 张新表，幂等迁移）

```sql
-- database/migration/20261107_add_user_quick_access.sql（重复执行保护：CREATE TABLE IF NOT EXISTS）
CREATE TABLE IF NOT EXISTS user_quick_access (
  id          BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id     BIGINT NOT NULL,
  item_key    VARCHAR(64) NOT NULL,      -- 对应 CARD_CATALOG 的 page.* 标识
  sort_order  INT NOT NULL DEFAULT 0,
  updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_item (user_id, item_key),
  KEY idx_user (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='工作台快捷访问个性化配置';
```

迁移脚本标注适用库（expert_system）与幂等保护，先在隔离测试库执行验证，再随发布流程上生产。

### 4.2 接口（对齐 layout 接口模式）

- `GET /api/dashboard/quick-access` → `{ items: ['page.project', ...] }`；未配置返回空（前端用默认）。
- `PUT /api/dashboard/quick-access`，body `{ items: [...] }`：服务端逐项校验 `item_key ∈ page.* 白名单` 且当前用户有权（capability 校验与 `/api/dashboard/overview` 同源），非法项拒绝整单（400）；全量覆盖写入（事务内删旧插新）。
- 登录校验沿用现有过滤器；无新权限点。
- 与 `user_dashboard_layout` 一致：**服务端不存标题/图标/路径**，展示信息始终来自前端目录，撤权后过期配置自动失效。

## 5. 设计规范落地（P2）

`DashboardView.vue` 样式块顶部集中定义变量（App.vue 头部所需变量放全局样式或 App.vue scoped 顶部）：

```css
:root { --c-primary:#2563EB; --c-page-bg:#F8FAFC; --c-card-bg:#FFFFFF;
        --c-text:#0F172A; --c-text-sub:#64748B; --c-border:#E2E8F0;
        --r-card:12px; --r-btn:8px; --h-header:60px; --pad-page:32px;
        --shadow-card:0 1px 2px rgba(15,23,42,.06); }
```

- 应用点：`.nav-card`、QuickAccessBar、UserMenu、DashboardView 面板边框/标题色、App.vue `.header` 高度与背景。
- Element Plus 组件（下拉/弹窗）通过现有全局样式覆盖主色，避免逐个覆写。
- 其他页面不在本期范围，变量不强制全局生效。

## 7. 风险与兼容

- **App.vue 全局改动是最大风险点**：页头影响所有页面，回归必须跨模块冒烟；登出逻辑仅复用不复制。
- Ctrl K 与浏览器/输入法冲突：仅注册 keydown 并检查 `isComposing`，与其他全局快捷键（如有）冲突时以先注册者优先，实施时核查现有全局快捷键清单（当前无，已核实）。
- 新表迁移为加表操作，无不可逆变更；回滚 = 还原 jar + 前端 conf 指针 + 表保留（无害）。
- 概念图中的表情符号、黄色圆形图标为示意素材，实现用现有图标库等价替换，不引入图片资源。
