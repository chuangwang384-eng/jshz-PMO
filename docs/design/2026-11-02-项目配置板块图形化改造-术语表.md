本节对应已施工、待业务验收的v3代码，生产尚未迁移。原文“未配置流程使用全部启用阶段”“无专属绑定回退通用”作为v2历史语义保留；v3显式区分如下概念，详细字段见 [实施说明](../deployment/2026-11-04-项目配置V3接口数据字典与发布步骤-部署说明.md)。

| 术语 | 含义 |
| --- | --- |
| 显式类型流程 | 类型发布时保存的有序阶段列表，至少一个阶段；新增公共阶段不自动加入其他类型。存量隐式列表在迁移时固化。 |
| 阶段要求模式 | INHERIT沿用通用、CUSTOM为类型单独配置、NONE无需提交材料；CUSTOM全选填仍是独立配置，不回退通用必填。 |
| 类型配置版本 | 项目类型的一次完整、不可变定义，发布指针选择当前版本，历史版本保留。 |
| 项目配置快照 | 项目创建时解析出的有效阶段、名称、材料类别和必填规则；项目运行只使用该快照。 |
| 存量基线快照 | LEGACY_BASELINE，仅代表迁移时的有效规则，无法还原没有留存的原始创建配置。 |
| 展示位置 | 全部项目类型的唯一连续名次1～N，与每个项目内的阶段顺序是两件事。 |
| 员工提交要求 | 面向使用者替代“阶段模板绑定”的页面表述；仍不在配置页面提交真实业务材料。 |
