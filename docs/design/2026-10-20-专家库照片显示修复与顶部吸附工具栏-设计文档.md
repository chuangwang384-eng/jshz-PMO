## 背景

1. **照片不显示**：数据库 148 条记录中 138 条已有照片（字段存 `avatar_N_时间戳.jpg`，文件全部存在于 `demo/uploads/`，`/uploads/` 路由访问正常）。员工页上一轮 UI 精简时卡片只用首字渐变头像，未渲染照片字段；管理页照片列有 img 但无加载失败兜底。
2. **搜索与下载常驻悬浮**：用户希望搜索框 + 下载按钮组在滚动页面时不消失，常驻可见。

## 需求一：照片显示修复

### 方案

- **员工页卡片头像**：优先显示照片（`/uploads/<照片字段>`），照片缺失或加载失败时自动回退为首字渐变头像。
- **管理页表格头像**：保留照片 img，加载失败时回退为首字渐变占位。

### 实现方式

采用「底层占位 + 上层照片」叠层结构，避免复杂 onerror 替换逻辑：

```html
<div class="avatar-wrap">
  <div class="avatar">首字</div>            <!-- 底层：首字渐变头像 -->
  <img class="avatar" src="/uploads/xxx" onerror="this.style.display='none'">  <!-- 上层：照片，失败隐藏露出底层 -->
</div>
```

- `.avatar-wrap` 相对定位，内部绝对定位铺满（52x52 / 40x40）。
- 照片加载成功即盖住首字；加载失败 `onerror` 隐藏 img，露出首字占位。

## 需求二：顶部吸附工具栏（方案 A：CSS sticky）

### 方案

将「搜索框 + 全选 + 下载按钮组」合并为一个吸附工具栏，置于列表/表格上方：

```css
.sticky-bar {
  position: sticky;
  top: 64px;               /* 顶栏 56px + 8px 间距 */
  z-index: 50;
  background: rgba(255,255,255,.94);
  border: 1px solid #e6e8ee;
  border-radius: 10px;
  padding: 12px 16px;
  margin-bottom: 16px;
  box-shadow: 0 2px 10px rgba(16,24,40,.08);
  display: flex; align-items: center; gap: 8px; flex-wrap: wrap;
}
.sticky-bar .info { margin-left: auto; }
```

- 纯 CSS 实现，零 JS、无抖动；滚动时吸附在顶栏下方，不随列表内容滚走。
- 员工页、管理页均应用。
