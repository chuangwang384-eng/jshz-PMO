## 1. 现状事实（已核实，2026-11-07）

- 面板渲染：`DashboardView.vue` 单文件；卡片目录 `CARD_CATALOG`（stat.* 4 项 / panel.* 6 项 / page.* 10 项），默认布局 `DEFAULT_LAYOUT`，权限过滤 `canShow(id)`（`perm` + `cap`）。
- 布局：`layoutEnabled = VITE_DASHBOARD_LAYOUT_V2 === 'true'`，保存值含卡片标识、顺序、宽度；浏览模式 CSS Grid，编辑模式原生拖拽。
- 项目行：`.item-row.project-row`（1.0.34.1 引入），行内容为 inline 文本串联，渲染 `lastPhaseChange.time` 为后端 ISO 原文。
- 时间字段来源：`DashboardController` 返回的 `lastPhaseChange.time`、`publishTime`、`favoriteTime`、`time` 等均为字符串，前端未格式化。
- 统计卡：4 张 stat 卡（待我审批/退回待修改/已逾期项目/今天·七天内到期），非 0 时带彩色底与重复副标题。
- 头部：问候 `h1` + 副标题 + 日期 + 刷新按钮 + 全局搜索 + 快捷入口纵向堆叠。

## 2. 方案设计

### 2.1 头部压缩（需求 3.1）

仅 CSS + 模板微调，DOM 结构不重排：

- 问候区：`h1` 字号由当前最大字号下调至约 20px（与板块标题同级），行内与副标题平齐；问候语、日期、`刷新工作台` 按钮合并为一行 flex，右对齐。
- 问候区上下 margin 由约 28px 收敛至 12px。
- 搜索框与快捷入口的 DOM 位置、行为、样式类不变。

### 2.2 KPI 卡降噪（需求 3.2）

- 模板：删除 stat 卡内与标题语义重复的副标题 span，改为标题左、数字右的单行 flex（或 `标题 (数字)`，实现取视觉更优者）。
- 样式：新增 CSS 变量 `--stat-quiet-bg`（近白底/细描边），数值为 0 时应用 `.is-zero` 类；仅 `stat.riskOverdue` 数值 > 0 保留 danger 高亮，其余非 0 数值使用中性强调色。
- 卡宽 `w=3` 不变，用户可在编辑模式自行调整。

### 2.3 项目行结构化（需求 3.3）

`.project-row` 内部由 inline 文本改为对齐网格：

```
[ 名称列（flex:2，项目名 + 风险 el-tag） ] [ 属性列（flex:3，四个固定子项） ] [ 详情 → ]
属性子项（各占固定宽度，竖向对齐）：阶段 / 负责人 / 结束日期 / 最近推进
```

- 数据全部来自现有 `data('myProjects').items` 字段（`phaseName/ownerName/endDate/lastPhaseChange/myRelations/warning`），不新增字段、不改接口。
- 风险标签沿用 `warningNames` 现有映射与 `OVERDUE?'danger':'warning'` 规则；`warning==='OVERDUE'` 的行加 `.is-overdue`（顶部 2px danger 边线）。
- 「我的角色」保留为名称列下第二行小字；「详情 →」位置不变。
- 长项目名换行时属性列保持对齐（属性列 `min-width` + `word-break` 约束）。

### 2.4 时间格式化（需求 3.4）

文件内新增工具函数（项目无日期库依赖，不引入 dayjs）：

```js
function fmtTime(iso){ if(!iso) return ''
  const d = new Date(iso); if (isNaN(d)) return iso      // 防御：非 ISO 原样返回
  const now = new Date()
  const y = d.getFullYear() !== now.getFullYear() ? `${d.getFullYear()}年` : ''
  const hm = `${String(d.getMonth()+1).padStart(2,'0')}月${String(d.getDate()).padStart(2,'0')}日 ${String(d.getHours()).padStart(2,'0')}:${String(d.getMinutes()).padStart(2,'0')}`
  return y + hm }
```

应用点：`lastPhaseChange.time`、公告 `publishTime`、收藏 `favoriteTime`、通知 `time`。`endDate`（业务截止日）保持 `YYYY-MM-DD` 原样。问候区日期 `2026-11-07` 与"最近刷新"时刻保持现状。

### 2.5 颜色降噪（需求 3.5）

页面样式集中在 `DashboardView.vue` 底部 `<style>`，本次统一：

- 新增变量：`--tone-danger-quiet`、`--tone-warning-quiet`（极淡底色）及对应边线色。
- stat 卡与风险行底色/边线改用变量；`button:focus-visible` 等全局规则不动。

## 3. 不改动清单（回归红线）

1. `CARD_CATALOG`、`DEFAULT_LAYOUT`、`canShow`、`sectionRequests` 数据流、`refresh` 键名。
2. 布局编辑：拖拽/缩放/保存/取消/恢复默认/冲突提示、`user_dashboard_layout` GET/PUT、窄屏单列规则。
3. **空面板展示形态**：空数据时"暂无…"占位文案与卡片占位保持现状，不折叠、不合并。
4. 路由跳转 `go(target)`、全部「查看全部」目标、`router.push('/project?mine=1')` 等。
5. 后端接口、`capabilities` 缓存（sessionStorage 键）、首帧预取逻辑。
6. `SectionState` 组件的加载/错误/重试形态。
