日期 2026-11-07 · 状态：待评审 · 关联需求：[2026-11-07-个人工作台信息密度优化-需求文档](../requirements/2026-11-07-个人工作台信息密度优化-需求文档.md)

本设计在 `frontend/src/views/dashboard/DashboardView.vue` 单文件内完成，纯前端展示层改造：**无后端变更、无数据库迁移、无路由变更、无新依赖**。布局编辑逻辑（`user_dashboard_layout` 持久化、12 列网格、编辑模式）与卡片目录（`CARD_CATALOG`）保持现状。

## 1. 现状事实（已核实，2026-11-07）

- 面板渲染：`DashboardView.vue` 单文件；卡片目录 `CARD_CATALOG`（stat.* 4 项 / panel.* 6 项 / page.* 10 项），默认布局 `DEFAULT_LAYOUT`，权限过滤 `canShow(id)`（`perm` + `cap`）。
- 布局：`layoutEnabled = VITE_DASHBOARD_LAYOUT_V2 === 'true'`，保存值含卡片标识、顺序、宽度；浏览模式 CSS Grid，编辑模式原生拖拽。
- 项目行：`.item-row.project-row`（1.0.34.1 引入），渲染 `lastPhaseChange.time` 为后端 ISO 原文。
- 时间字段来源：`DashboardController` 返回的 `lastPhaseChange.time`、`publishTime`、`favoriteTime`、`time` 等均为字符串，前端未格式化。
- 统计卡：4 张 stat 卡（待我审批/退回待修改/已逾期项目/今天·七天内到期），非 0 时带彩色底。

## 2. 方案设计

### 2.1 空状态折叠（需求 3.1）

新增纯前端派生状态，不动布局数据：

```js
const isEmptyPanel = (key) => {
  const s = section[key]
  if (!s || s.status !== 'success') return false   // 加载/错误态不折叠，保持 SectionState 提示
  const d = data(key)
  return !(d?.items?.length)                        // items 为空即折叠
}
```

- 模板：`panel.*` 分支内 `<template v-if="!isEmptyPanel(sectionKey)">原完整内容</template><div v-else class="panel-empty-bar">…</div>`。
- `.panel-empty-bar`：单行 flex（文案 + 「查看全部」/「刷新」），高度约 44px；卡片外框保留但内容收缩，网格行高随内容自适应（浏览模式 grid 为 auto 行，无需改持久化结构——**实现前须确认行高机制**；若行高由已保存 h 决定，则折叠态改为 `grid-row: auto` 覆盖，仅浏览模式生效）。
- 编辑模式（`layoutEnabled && editing`）：跳过折叠判断，始终渲染完整卡片，保证拖拽预览与保存结果一致。
- 错误/加载态不折叠，避免掩盖 SectionState 的重试入口。

### 2.2 时间格式化（需求 3.2）

文件内新增工具函数（项目无现成日期库依赖，不引入 dayjs）：

```js
function fmtTime(iso){ if(!iso) return ''
  const d = new Date(iso); if (isNaN(d)) return iso      // 防御：非 ISO 原样返回
  const now = new Date()
  const y = d.getFullYear() !== now.getFullYear() ? `${d.getFullYear()}年` : ''
  const hm = `${String(d.getMonth()+1).padStart(2,'0')}月${String(d.getDate()).padStart(2,'0')}日 ${String(d.getHours()).padStart(2,'0')}:${String(d.getMinutes()).padStart(2,'0')}`
  return y + hm }
```

应用点：`lastPhaseChange.time`、公告 `publishTime`、收藏 `favoriteTime`、通知 `time`。`endDate`（业务截止日）保持 `YYYY-MM-DD` 原样。问候区日期 `2026-11-07` 保持现状。

### 2.3 头部压缩（需求 3.3）

仅 CSS + 模板微调：问候区 `h1` 字号下调至与正文标题同级（约 20px），问候语、日期、刷新按钮合并为一行 flex（右对齐）；垂直 margin 由约 28px 收敛至 12px。搜索框与快捷入口 DOM 位置不变。

### 2.4 KPI 卡降噪（需求 3.4）

- 模板：删除 stat 卡内与标题重复的副标题 span，改为 `标题 (数字)` 或标题左、数字右单行。
- 样式：新增 CSS 变量 `--stat-quiet-bg`（近白描边）；数值为 0 时应用 `.is-zero`；仅 `stat.riskOverdue` 数值 > 0 保留 danger 高亮。卡宽 w=3 不变，可由用户在编辑模式自行调整。

### 2.5 项目行结构化（需求 3.5/3.6）

`.project-row` 内部由 inline 文本改为两列对齐网格：

```
[ 名称列（flex:2，含风险 el-tag） ] [ 属性列（flex:3，四个固定子项竖向对齐） ] [ 详情 → ]
属性子项：阶段 / 负责人 / 结束日期 / 最近推进（有则显示，含格式化时间与推进|回退文案）
```

- 数据全部来自现有 `data('myProjects').items` 字段（`phaseName/ownerName/endDate/lastPhaseChange/myRelations/warning`），不新增字段。
- 风险标签沿用 `warningNames` 现有映射与 `OVERDUE?'danger':'warning'` 规则；逾期行加 `.is-overdue`（顶部 2px danger 边线）。
- 「我的角色」保留为属性子项或第二行小字（实现时取对齐效果更优者，不影响验收）。

### 2.6 颜色降噪（需求 3.7）

页面样式集中在 `DashboardView.vue` 底部 `<style>`，本次统一：
- 新增变量：`--tone-danger-quiet`、`--tone-warning-quiet`（极淡底色）与对应边线色。
- stat 卡与面板底色改用变量；hover/焦点样式不动；`button:focus-visible` 全局规则不动。

## 3. 不改动清单（回归红线）

1. `CARD_CATALOG`、`DEFAULT_LAYOUT`、`canShow`、`sectionRequests` 数据流、`refresh` 键名。
2. 布局编辑：拖拽/缩放/保存/取消/恢复默认/冲突提示、`user_dashboard_layout` GET/PUT、窄屏单列规则。
3. 路由跳转 `go(target)`、全部「查看全部」目标、`router.push('/project?mine=1')` 等。
4. 后端接口、`capabilities` 缓存（sessionStorage 键）、首帧预取逻辑。
5. `SectionState` 组件的加载/错误/重试形态。

## 5. 风险与兼容

- **布局持久化兼容**：折叠仅影响浏览态渲染，不写布局数据，老用户保存结果零影响（实现阶段需验证行高机制假设，见 2.1）。
- **回归范围**：单文件改动，回归面限于工作台页；其他页面零接触。
- **发布风险**：与 1.0.29/1.0.30 前例相同，仅前端静态资源切换，可按 release-metadata 回滚。
- **未决项**：需求 §6 三个决策点（内联审批、Ctrl+K、折叠开关）未确认前不实现；若纳入需按 AGENTS.md 第 5/6 节补充权限与安全评估。
