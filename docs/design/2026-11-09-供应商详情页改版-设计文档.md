## 1. 总体结构

```
┌ 返回供应商列表 ······································ [编辑] [删除] ┐
│ ┌ 主面板（flex:1） ────────────────────────┐ ┌ 同城供应商 320px ┐ │
│ │ 名称 + 类型标签              供应商档案    │ │ 搜索名称          │ │
│ │ [基本资料][图片管理][历史价格][服务评价]   │ │ 全部类型 ▾        │ │
│ │ ──────────────────────────────────────── │ │ · 名称            │ │
│ │ Tab 内容（单 Tab 渲染，其余 v-show）        │ │   类型 ›          │ │
│ └──────────────────────────────────────────┘ └──────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

- 布局：`.layout` flex，主面板 `flex:1; min-width:0`，侧栏固定 320px（`position:sticky`）。
- `<1200px`：侧栏隐藏，顶部出现「同城供应商（N）」按钮，点开同一个抽屉，**复用同一份筛选状态**（`cityKeyword` / `cityTypeFilter` / `sameCityList`）。

## 2. 关键实现

### 2.1 Tab 化

- `activeTab` 为本地状态，`tabs` 为 computed：`基本资料 / 图片管理 / 历史价格 / 服务评价`，酒店/打印店额外追加 `绑定打印店 / 服务的酒店`。
- 内容区用 `v-show` 而非 `v-if`：保留各 Tab 内部的滚动位置与表单状态，切换零请求。
- `watch(tabs)`：供应商类型变化导致某 Tab 消失时（例如酒店→媒体），自动回落到 `基本资料`，避免空白页。
- 样式：选中态为深色胶囊（`#1f2329` 底 + 白字），未选中透明底灰字，hover 浅灰。

### 2.2 基本资料分组

- 三个 `<section class="sec">`：基础资料 / 联系信息 / 业务介绍，最后是折叠的档案信息。
- `cityAddressText` computed 合并 `province · cityName` + 地址（全角空格分隔），避免城市与地址各占一行。
- 复制：`copyText(text, label)`；安全上下文用 `navigator.clipboard.writeText`，否则建临时 textarea + `execCommand`，成功后 `ElMessage.success`。

### 2.3 图片管理

- 网格：`repeat(auto-fill, minmax(180px,1fr))`，缩略图 `aspect-ratio:4/3`，保证不同尺寸图片视觉一致。
- 操作层：绝对定位覆盖缩略图区域，`opacity 0 → 1` 悬停显示，四个圆形图标按钮（预览/设主图/重命名/删除），各自带 `el-tooltip`。
- 预览：`el-image-viewer`（Element Plus 全量注册，无需额外引入），由「预览」按钮控制 `viewerVisible` + `viewerIndex`。
- 命名：删除顶部输入框，上传时不再传 `name`；重命名弹窗内展示该图缩略图与原文件名，调用既有 `PUT /supplier/{id}/images/{imageId}/name`。
- 权限沿用：上传/重命名 `supplier:image`，设主图/删除 `supplier:manage`。

### 2.4 历史价格

数据层：

- 迁移 `database/migration/20261109_supplier_price_quote_date.sql`，`information_schema` 判存后 `ALTER TABLE supplier_price_item ADD COLUMN quote_date DATE NULL / valid_until DATE NULL`（幂等、可重复执行）。
- 实体 `SupplierPriceItem` 增 `LocalDate quoteDate / validUntil`，`@JsonFormat(pattern="yyyy-MM-dd")`。
- `SupplierService.savePrices` 解析 `quoteDate`/`validUntil`（允许空、允许带时间串截前 10 位），并校验**有效期不得早于报价日期**，非法格式报「格式应为 yyyy-MM-dd」。

展示层：

- `priceState(p)`：无 `validUntil` → 长期有效（绿）；`validUntil < 今天` → 已过期（灰）；否则 有效（绿）。日期为 `yyyy-MM-dd` 字符串，可直接字典序比较。
- 报价日期空时回退 `createTime` 前 10 位。
- 金额格式化：`toLocaleString('zh-CN')`，最多两位小数，单位以 `/单位` 后缀呈现（如 `¥1,280/人`）。
- 汇总行用 `validPriceCount` computed。

### 2.5 服务评价

- `stats` computed：条数、5→1 星分布数组、平均分；优先用后端 `avgStars`，否则本地计算 `toFixed(1)`。
- 分布条：宽度 = 该星级条数 / 总条数，黄色 6px 圆角条。
- 新增评价：`el-dialog` + 星级点选 + textarea，成功后 `fetchDetail()`；按钮挂 `supplier:manage`（与后端一致）。

### 2.6 同城供应商

- 数据仍复用 `GET /api/supplier/list?cityId=…&page=1&size=200`，不新增后端接口。
- `sortedSameCity`：排除当前 `route.params.id`，已绑定优先、其次按 `localeCompare('zh-CN')` 名称排序。
- 类型下拉选项来自 `sameCityTypes`（同城列表中实际出现的类型去重），天然只列出有数据的类型。
- 名称不截断：`white-space` 默认换行 + `word-break:break-word`；类型在第二行，已绑定加小号 tag。
- 切换：`router.push('/supplier/:id')` 复用同一组件实例，`cityKeyword` / `cityTypeFilter` / `activeTab` **不重置**（仅在 `route.params.id` 变化时 `fetchDetail()`），因此筛选条件保留。
- 返回：`goBack()` 优先 `router.back()`（有历史时），否则 `push('/supplier')`。

### 2.7 列表页查询状态入 URL（配套）

`SupplierList.vue`：

- `initFromRoute()`：从 `keyword/typeId/cityId/onlyReviewed/sort/page/pageSize/view` 还原筛选、页码与视图。
- `syncRouteQuery()`：`fetchList()` 前置调用，状态变化时 `router.replace({ query })`（只 replace，不 push）；默认值不写入 URL。
- `setViewMode()` 同步写 URL；`view` 缺失时回退 `localStorage` 记忆。
- 效果：列表 → 详情 → 返回（`router.back()`）能还原搜索词、筛选、页码与视图。

## 3. 权限与兼容

| 操作 | 权限码 | 变化 |
|------|--------|------|
| 编辑/删除供应商、设主图、删图、跨城清单 | `supplier:manage` | 不变 |
| **提交服务评价** | **`supplier:review`** | **1.0.37.22 从 `supplier:manage` 拆出，绑定全部非超管角色** |
| 上传图片、重命名图片 | `supplier:image` | 不变 |
| 维护历史价格 | `supplier:price` | 不变 |
| 绑定/解绑 | `supplier:binding` | 不变 |

- 后端接口路径不变，仅 `POST /api/supplier/*/reviews` 的鉴权码由 `supplier:manage` 改为 `supplier:review`（`permission` 表第 195 行原地改码，不新增行——`DbPermissionFilter` 按 id 升序命中第一条即校验，留旧行会让非 ADMIN 继续 403）。
- 前端入口不再用 `v-permission` 指令（只在 mounted 判一次，`fetchMe` 刷新权限后不会重新挂载），改用响应式 `canReview = hasPermission('supplier:review')` + `v-if`。
- `PermissionService` 的规则集与用户权限集都有进程内缓存，改库后需重启/蓝绿发布后端才生效；前端 `App.vue` 启动时 `fetchMe()` 会拿到新权限，无需重新登录。

- 后端接口路径与鉴权规则零改动，仅 `PUT /supplier/{id}/prices` 的 body 多接受两个可选字段。
- 旧前端调新后端 / 新前端调旧后端均不会 500：新增字段可空，旧前端不传即 NULL。

## 4. 风险与回滚

| 风险 | 处置 |
|------|------|
| 迁移未执行就切后端 | 后端正 SELECT 新列会报错；发布脚本**强制迁移先于后端**，迁移失败即中止全流程 |
| 迁移重复执行 | `information_schema` 判存，幂等 |
| 日期格式非法 | 后端校验并返回明确文案，不落脏数据 |
| 视觉回退 | 前端 graceful 切 root，旧 release 目录完整保留，`scripts/rollback-frontend.ps1` 可回切 |
| 列回滚 | `ALTER TABLE supplier_price_item DROP COLUMN quote_date, DROP COLUMN valid_until;`（先备份） |
