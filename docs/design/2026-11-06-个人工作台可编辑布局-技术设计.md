日期 2026-11-06 · 待评审

## 实现基线

当前 Vue 3 / Vite 工作台由 DashboardView.vue 渲染，卡片目录以稳定 ID 管理，权限基于 auth 权限与 overview capabilities。DashboardController 的 GET/PUT /api/dashboard/layout 以认证账号为主键读写 user_dashboard_layout.layout，旧协议使用 JSON 文本。现有前端归一化会把旧五字段布局读成 {i,w}，并把空数组当成无布局。发布记录显示 1.0.29 的 grid-layout-plus 引入后，Edge 在登录后渲染工作台时崩溃，1.0.30.1 移除该依赖后恢复。见 [崩溃复盘](../releases/20261106-dashboard-layout-crash-fix-1.0.30.1.md)。

## 前端结构与交互

- DashboardView 继续负责业务数据、权限、卡片目录、详情跳转与回到工作台刷新。布局适配器负责把稳定卡片 ID 映射到 Vue 内容并协调 GridStack 生命周期，现有卡片功能通过目录注册。
- 桌面 12 列，建议初始行高 48 CSS 像素、间距 8 CSS 像素，原型验证后固定。浏览与编辑复用同一套几何、容器和卡片内容，浏览关闭移动和缩放。编辑使用独立快照，拖拽与缩放结束后读出整张网格，包含碰撞后移动的卡片，禁止只保存主动拖动的卡片。
- 原型验证保留空位的 GridStack 模式及加载顺序。碰撞预览与结束位置必须一致，超出画布行上限时恢复本次动作前快照。键盘操作经同一网格实例执行。业务滚动区与拖拽手柄分离。窄屏用同一份数据按 y、x、ID 排序后静态单列展示。
- 将编辑器作为延迟加载的模块。发布时默认走静态浏览路径，开关控制桌面网格和编辑器。开关关闭时用已验证的静态渲染显示可用布局，待办和风险仍可用。异步加载异常走静态回退。浏览器渲染进程崩溃无法靠 Vue 捕获，必须通过发布前 Edge 门禁与服务端开关处置。
- 每次打开编辑生成一份已保存布局副本，保存时冻结提交，失败保持编辑。离开页面时清理监听器和 GridStack 实例。响应式切换、权限刷新或加载旧数据期间产生的网格事件不写服务端。

## 数据、API 与兼容

- 复用 user_dashboard_layout，建议新增可空的 layout_v2 JSON 列，内部保存 schemaVersion、revision 和 items。items 每项为 {i,x,y,w,h}，坐标从零开始，尺寸为正整数。建议画布最大 200 行，单卡最大高度 24 行，最小尺寸由模块目录定义。空 items 为有效布局。DDL 先核对隔离和目标库元数据，再提供幂等迁移及备份回滚说明。
- GET/PUT /api/dashboard/layout/v2 只按已认证账号读写。GET 返回当前快照和 revision，PUT 携带所见 revision。服务端事务内比较版本、验证与写入。初次写入的并发场景使用唯一 user_id 约束处理，冲突返回 409，不覆盖其他窗口的编辑。兼容期保留原 GET/PUT。若旧版 PUT 后有更新，保留两份数据并让新版读取时提示重新加载或确认采用旧版变更。实施时通过事务内同步记录旧值的规范化指纹识别变更，旧接口不需要了解新列。
- 初次读取时，合法的历史 {i,x,y,w,h} 尽量保留坐标；{i,w} 按顺序放入 12 列网格，高度取目录默认。遇到过期 ID、重叠或越界，跳过未知项并按确定性规则重排有问题的卡片。旧空数组继续按旧版含义回到默认；新协议的空数组保持为空。迁移只在用户显式保存时写入新版列。
- 新写入服务端校验大小上限、条目数、唯一 ID、目录白名单、账号当前权限、整数、边界、模块尺寸与矩形重叠。GET 也过滤当前无权卡片。服务端复用工作台权限来源，权限过滤不因客户端布局而改变业务数据的访问范围。无效输入返回可读错误，日志不记录业务内容或凭证。
- 新版保存事务同步将卡片按 y/x 顺序投影为旧 {i,w} 到原列，回退至稳定静态版本时能读到顺序和宽度。新版坐标保留在独立列，恢复新版时可继续使用。旧版无法表现高度和空白位置，旧空布局降级时可能显示默认卡片。

## 验证与上线门禁

1. 原型在隔离目录构建生产包，以项目使用的真实 Edge 通道跑登录落地、直接进入工作台、反复切换编辑、移动、缩放、刷新和窄屏切换。监听 page crash、pageerror 和接口失败，验证业务卡片内容、焦点和链接。用现有静态版作为对照。出现崩溃即停止选型推进。
2. 通过隔离 MySQL 验证迁移重复运行、旧数组转换、空布局、读取和写入隔离、未知卡片及权限拒绝、冲突、事务一致性和旧版回读。真实 Edge 校验多个分辨率和有无审批权限的账号，断言保存前后每张卡的 x/y/w/h，并复验项目到期风险和事项返回刷新。
3. 发布候选必须复用已验收制品并校验哈希。先验证关闭开关的静态回退，再在获批环境灰度开启。遇到崩溃、空白或存储错误，先关闭编辑开关，必要时回退到已确认无工作台崩溃的前端制品。保留新增列及版本数据。生产操作遵循现有审批和备份流程，禁止在运行中制品目录构建。
4. 实施阶段同步接口、架构、数据字典、部署与测试文档，记录 Edge 版本、制品哈希、测试命令和结果。本次仅完成设计评审材料，尚未执行原型、构建、数据库迁移或浏览器验收。

## 实施细节

采用 GridStack 核心引擎与 Vue 控制卡片内容的适配器，渲染引擎只在编辑模式初始化。栅格行步长 56 CSS 像素，四边各 4 像素。宽屏浏览使用与编辑相同的几何规则。旧协议保留独立读写，revision 绑定旧投影与新版快照。开关 VITE_DASHBOARD_LAYOUT_V2 为构建期开关，回退切换静态制品。见 [接口和部署说明](../deployment/2026-11-06-工作台二维布局-接口部署与验收.md)。

### 编辑与浏览的卡片尺寸

编辑和浏览分别挂载网格容器。切换时先释放 GridStack 对旧容器的管理，避免内联尺寸进入静态布局。编辑控件悬浮在卡片左下角，独立于正文尺寸。统计卡和快捷入口卡居中显示，说明保留必要短语，项目到期判定和数据口径沿用原规则。
