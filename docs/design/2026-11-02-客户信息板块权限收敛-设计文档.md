# 客户信息板块权限收敛 详细设计文档（DDD）

## 1. 设计概述

本设计解决客户信息板块权限越权问题：普通员工（EMPLOYEE）在客户详情页可见"关系类型管理"按钮、可直达管理页、可调用管理配置只读接口；同时补齐附件下载审计留痕，并清理知识文档分类残留死分类。

总体策略：**前端按钮 + 路由守卫 + 后端接口校验三层收敛**，业务展示（关系圈、关系图）与附件下载权限保持不变，仅增加下载审计。

## 2. 模块结构与依赖

- **入口层**：`CustomerController`（Java 17 / Spring Boot 3）
- **业务逻辑层**：`CustomerService` / `CustomerRelationService` / `KnowledgeDocumentService`
- **数据持久层**：`customer_relation_type` 表、`permission` 表、`operation_log` 表
- **前端**：`CustomerDetail.vue` / `CustomerRelationTypeManage.vue` / `router/index.js` / `directives/permission.js`

### 3.3 数据库改动（SQL 迁移）

SELECT 'customer:manage', '客户管理-关系类型列表', 2, 'GET', '/api/customer/relations/types', ...

    SELECT 1 FROM permission
    WHERE method = 'GET' AND path = '/api/customer/relations/types'

## 4. 接口定义（变更部分）

### 4.1 GET /api/customer/relations/types

- **变更前**：仅登录（`requireUser`）→ 普通员工可查看关系类型列表。
- **变更后**：仅 `customer:manage`（`requireManage` + `DbPermissionFilter` 规则）。
- **响应**：无权限返回 403（与系统现有无权限响应一致）。
- **影响面**：仅关系类型管理页使用该接口；详情页关系圈使用 `GET /api/customer/{id}/relations`，不受影响。

### 4.2 GET /api/customer/files/{fileName}

- **权限**：保持仅登录（**不变**），不新增权限规则、不做附件归属校验。
- **新增**：下载成功后写 `operation_log`，事件类型 `DOWNLOAD_CUSTOMER_ATTACH`，字段：user_id、username、fileName、ip、create_time（如请求链路可取得 customerId 一并记录）。
- **异常**：日志写入失败仅记录告警，不阻断文件下载响应。

### 4.3 保持不变的接口

| 接口 | 权限 | 说明 |
|------|------|------|
| `GET /api/customer/{id}/relations` | 仅登录 | 详情页关系圈，普通员工保留 |
| `GET /api/customer/relations/network` | 仅登录 | 全局关系网络图，普通员工保留 |
| `POST /api/customer/relations/types` | `customer:manage` | 新增类型，不变 |
| `PUT /api/customer/relations/types/{id}` | `customer:manage` | 编辑类型，不变 |
| `POST /api/customer/relations` | `customer:manage` | 新增关系，不变 |
| `DELETE /api/customer/relations/{id}` | `customer:manage` | 删除关系，不变 |
| `POST /api/customer/{id}/attachments` | `customer:manage` | 上传附件，不变 |
| `DELETE /api/customer/attachments/{attachmentId}` | `customer:manage` | 删除附件，不变 |

- 仅 `permission` 表新增 1 条接口规则（幂等）；`operation_log` 表复用现有结构，不新增字段。

## 6. 异常处理

| 异常场景 | 处理策略 |
|----------|----------|
| 普通员工直达管理路由 | 路由守卫拦截，重定向至首页/403 页 |
| 普通员工直接调用 `GET /api/customer/relations/types` | `DbPermissionFilter` 或 `requireManage` 返回 403 |
| 下载日志写入失败 | 日志记录失败不阻断下载；告警由日志系统处理 |
| 知识文档上传携带 `customer-preferences` 分类 | 白名单校验失败，返回 400，提示分类不合法 |
