## 1. 项目定位与一个关键判断
系统全称"景帅会展内部管理系统"（专家库/OA），纯内网部署。架构为单机 Windows：Nginx(80, NSSM 服务 `ExpertSystemNginx`) 托管前端静态文件并反代 `/api/` → Spring Boot(8080, NSSM 服务 `ExpertSystemBackend`) → MySQL 8.x（expert_system 库）。

**关键判断：当前工作副本 <LOCAL_PATH> 极大概率就是生产服务器的部署目录本身**（置信度高，建议当面确认）。证据：nginx 配置指向 <LOCAL_PATH> 有今天上午 09:16/09:28 两份发布归档、deployment.md 记录"2026-10-26 09:29:01 发布 1.001 成功"。**含义：在这台机器上任何构建、改 jar、重启服务都等于生产变更，后续一切操作需按生产规范走。**

## 4. 前后端架构要点
**后端**（入口 `ExpertSystemApplication`，端口 8080，无 context-path）：经典三层 + 统一响应 `{code=0成功, message, data}`；全局异常 `GlobalExceptionHandler`；13 个 Mapper 全部继承 MyBatis-Plus BaseMapper，**0 个 XML**（仅 DownloadLogMapper 2 个注解 SQL）；无多数据源，显式事务仅知识文档模块。

**鉴权与权限（核心链路）**：登录=员工姓名+密码（BCrypt，姓名规则匹配+初始密码即**自动注册**）→ JWT(HS256, 8h) 写入 **httpOnly cookie** `expert_token`（secure=false）→ `JwtAuthenticationFilter`（Bearer/cookie 双通道）→ `DbPermissionFilter` 按 permission 表 method+Ant 规则校验权限码（未命中规则仅要求登录）→ 前端路由 meta.permissions（some 任一命中）+ `v-permission` 按钮级指令（`*` 通配=SUPER_ADMIN）。RBAC 五表模型；首登/重置后 mustChangePassword 弹不可关闭改密框。企微登录 3 个端点为占位（固定 enabled=false，标注二期）。

**文件上传**：管理员直传照片（/api/upload/photo、/api/upload/idcard，≤5MB 白名单）；员工改档走审批临时上传 /api/approval/photo-upload，提交时 `TMP:` 前缀归档；知识文档 ≤50MB；Excel 导入走 POI。下载/导出统一写 download_log 留痕（含 IP）。存储为硬编码 Windows 绝对路径（照片库/知识文档库）。

**通知**：7 类事件写 notification 表 → 前端 NotificationBell 每 30s 轮询未读数，新增弹提示、可跳转 jumpPath。

## 6. 本地启动 / 构建 / 测试 / 部署
**⚠️ 前提**：本机疑为生产服务器。后端 8080 已被 NSSM 服务占用、target jar 被进程锁——本地再起后端必须换端口（如 8081）且不要动 target\expert-system-1.001.jar；`mvn package` 会因 jar 锁失败（文档已警告需先停服务，**不要随意停**）。

- 数据库初始化（新环境）：先 `mysql < database/init.sql`（仅 6 表），**必须再依次执行 database/migration/ 4 个脚本**才能到 13 表——README/deployment.md"init.sql 含 13 表"的说法不准确。
- 后端：设置环境变量 MYSQL_PASSWORD（application.yml 全部走 `${MYSQL_*}` 注入，默认空会连不上）；生产唯一合法启动方式是 start-backend.bat。dev 调试：`mvn spring-boot:run`（换端口）。
- 前端：`npm run dev` → http://localhost:5173，/api 自动代理到 127.0.0.1:8080（.env.development 可改）。
- 构建：前端 `npm run build`（vite）；后端 `mvn clean package -DskipTests`。
- 测试：后端仅 1 个空的 contextLoads 测试（JUnit5），前端无测试框架——**系统实际无自动化测试**，发布靠手工冒烟。
- 部署：`scripts/deploy-frontend.ps1`（构建到 dist-new.<时间戳>→备份→Rename 原子替换→SHA256 自检，不重启）；`scripts/deploy-backend.ps1`（11 阶段蓝绿：8081 影子→探测→切 Nginx→停服务换 jar→切回）；`rollback-frontend.ps1`（从 releases 恢复）。回滚目标 15 分钟。
