## 五、部署说明

1. **数据库**：将 `<LOCAL_PATH>` 以 utf8mb4 导入（含中文 SQL，禁止经 PowerShell 管道导入，需 `--default-character-set=utf8mb4` 重定向），脚本幂等可重复执行。
2. **后端**：NSSM 服务 ExpertSystemBackend（唯一合法启动方式 <LOCAL_PATH> `target\expert-system-1.007.jar`（pom 版本 1.007），**注意** NSSM AppParameters 固定名契约为 `expert-system-1.001.jar`，部署时需将产物重命名为契约名或同步调整 AppParameters，否则服务启动会加载旧 jar。发布可用 scripts/deploy-backend.ps1 蓝绿发布。
3. **前端**：NSSM 服务 ExpertSystemNginx（托管 frontend/dist，listen 80 反代 /api/ → 127.0.0.1:8080）。发布可用 scripts/deploy-frontend.ps1（备份+build+reload），回滚 scripts/rollback-frontend.ps1。
4. **权限生效**：需给目标用户绑定 PROJECT_OWNER 角色（SUPER_ADMIN 代码内全权自动获得）；project:view 全员默认无需绑定。
5. **合同审批流**：复用现有审批流配置（approval 模块），需确认审批流已启用（approval_config 存在且 enabled=1），否则发起合同审批会提示"审批流未启用"。
