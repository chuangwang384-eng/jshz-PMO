> 项目：jshz-PMO（景帅会展内部管理系统）
> 文档版本：v1.0（定稿）
> 日期：2026-10-31
> 状态：需求已确认，待实施

## 1. 背景与问题

现有页面普遍存在「顶部导航栏标题」与「内容区域标题」重复展示的问题：

- 顶部导航栏已展示当前页面名称（数据源为路由 `meta.title`），内容区域又写死展示同一文案标题，造成视觉重复。
- 重复标题与说明文字组合占用了额外的垂直空间，压缩了表格等业务数据的展示高度。
- 全项目核查（只读）：33 个路由页面中，**14 个页面确认存在标题重复**，**4 个页面存在文案/语义需确认问题**。

### 根因

同一文案既作为路由 `meta.title`（顶部导航与侧边菜单同源），又写死在页面组件内容区标题中。

## 2. 目标

1. 顶部导航栏负责展示当前页面名称。
2. 内容区域只负责业务说明、筛选条件、操作按钮和业务数据。
3. 删除内容区与顶部导航**逐字重复**的标题；保留承载业务差异/业务实体的标题。
4. 保留各页面原有辅助描述文字，统一为较小字号、浅灰色。
5. 适当压缩页面顶部留白，让表格获得更多垂直展示空间。

## 3. 非目标（本次不做）

- 不修改后端接口、数据库结构及业务逻辑。
- 不影响现有权限、审批、撤回、查看进度、查看对比等功能。
- 不改动业务数据、筛选逻辑与交互行为。
- 不做菜单结构调整、路由结构调整、权限调整。

## 5. 全局判定规则（统一规范）

- **顶部导航栏**：负责展示当前页面名称（`route.meta.title`）。
- **内容区域**：负责展示业务说明、筛选条件、操作按钮和业务数据。
- **允许保留内容区标题的情形**：内容区标题表达「业务实体名 / 操作对象 / 业务差异」（如客户姓名、供应商名、项目名、全局关系网络），且与顶部导航文案存在明确差异化信息时。
- **必须删除的情形**：内容区标题与顶部导航**逐字相同且无附加信息**时，一律删除，不得在同一页面无意义重复展示相同标题。

## 6. 样式与留白要求

1. 保留的辅助描述（page-sub）统一：**13px / #909399 / 与内容区顶部对齐**。
2. 页面顶部垂直留白统一为 **12px**（修改 `App.vue` `.main` 顶部 padding 16px → 12px，全局生效）。
3. 无辅助描述的页面，标题区块整体删除，后续内容（筛选器/工具栏/卡片）直接上移。

## 7. 验收标准

1. 全部整改页面不再出现与顶部导航逐字重复的内容区标题。
2. 辅助描述样式统一（13px / #909399），顶部留白 12px 全局生效。
3. 在 **1280×720 / 1366×768 / 1920×1080** 三档分辨率下检查：表格列不挤压、工具栏不换行、布局无错乱。
4. 现有功能回归通过：审批、撤回、查看进度、查看对比、权限控制均不受影响。
5. 无样式回归：已确认无标题问题的页面（专家库、用户管理等）仅受 4px 顶部留白变化影响，无副作用。

## 8. 术语表（Glossary）

| 术语 | 含义 |
|---|---|
| 顶部导航栏 | App.vue 顶部 header 区域，展示 `route.meta.title`（与侧边菜单同源） |
| 内容区域标题 | 页面组件模板中写死的 page-title / card-header 标题文字 |
| page-head / page-title / page-sub | 现有内容区标题区块的统一样式类 |
| 标题去重 | 删除内容区与顶部导航逐字重复标题的整改动作 |
| 差异化标题 | 内容区标题与顶部导航文案不同、且承载业务差异信息的标题，允许保留 |
