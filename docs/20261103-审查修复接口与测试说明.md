# 审查修复接口与验收说明

日期：2026-11-03；状态：开发实现，未发布。

| 接口/行为 | 本轮契约 |
| --- | --- |
| GET /api/project/{id}/timeline | URL和成功结构不变；后端新增项目资源权限校验；非成员无view-all返回业务403 |

隔离环境手动验收：
1. 非成员读他人时间线应403；负责人/执行人/view-all应正常；匿名仍走既有认证。
2. 关联有费用供应商再尝试删除应拒绝且名单/预算不变；移出后可删除；历史缺档行可见且可移出。并发关联/删除验证行锁一致性。
3. 同一模板保存两次，内容互不覆盖；删一条不影响另一条。旧共享路径删第一行保留文件，删最后行清理；模拟事务回滚不误删文件。
4. 固定时钟验证首次收藏默认提醒；取消收藏非责任人停止；责任人身份仍有效；关闭/完成/下架均停止。提前3/2/1/0天只在3和0发送，重复执行只一次。
5. 通知首次失败第二次成功只留一条；一直失败三次后FAILED；单节点日志提交故障不回滚先前节点。同库事务并发/回滚需真实隔离MySQL验证。
6. 类型新增三步保存刷新一致；编辑原样保存不改变绑定排序；阶段/模板拖动不丢数据；回第二步重排保留编辑；全局兜底计数包含空流程类型；加载失败禁保存；部分保存失败可重试；图/表切换一致。

本轮自动验证不替代真实数据库、浏览器交互和业务验收，严禁在生产执行调度故障注入。
