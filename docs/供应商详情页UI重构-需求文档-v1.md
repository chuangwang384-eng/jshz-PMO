## 1. 背景与目标

### 1.1 项目背景

| 维度 | 现状 |
|---|---|
| 技术栈 | 前端 Vue3 + Element Plus（默认主题）；后端 Java17 + Spring Boot3；数据库 MySQL8 |
| 现状详情页 | `<LOCAL_PATH>`（702 行单文件），单列全宽堆叠 5 个 el-card |
| 现有区块 | 头部信息卡、图片卡（150×110 缩略图网格）、行价卡（只读表格 + 弹窗全量编辑）、评价卡（提交表单 + 列表）、绑定关系卡（仅酒店/打印店类型显示） |
| 主要痛点 | ① 信息密度低；② 图片/行价数据少时底部大面积留白；③ 无同城市供应商快速导航；④ 评价与价格视觉层级弱 |

### 1.2 重构目标

1. 详情页三栏化布局，优化信息展示层级，降低留白、提高信息密度。
2. 新增右侧"同城市供应商"快速导航，提升运营查找效率。
3. 优化图片管理与历史价格的视觉呈现。
4. 保持与现有 OA 系统 UI 风格一致。

---

## 2. 改造原则

| 原则 | 说明 |
|---|---|
| 保留业务逻辑 | 不改变供应商维护、图片管理、价格维护、评价提交的既有业务规则 |
| 保留接口 | 优先复用现有后端接口，本轮不新增接口 |
| 保留数据库结构 | 不改表结构、不加字段（含城市字典、图片主图标记等） |
| 保留权限控制 | 沿用现有权限模型与最新生效的权限规则脚本 |
| 保持风格一致 | 视觉沿用 Element Plus 默认主题与 OA 系统既有风格 |

## 3. 页面布局需求

### 3.1 布局总览（三栏）

| 栏位 | 宽度 | 承载内容 |
|---|---|---|
| 左栏 | 340px | 供应商基本信息（紧凑两列） |
| 中栏 | 自适应（flex: 1） | 图片管理 / 历史价格 / 评价 三个卡片区块 |
| 右栏 | 280px | 同城市供应商导航 |
| 小屏（<1200px） | 右栏折叠 | 折叠为顶部可展开按钮（抽屉 + 遮罩） |

### 3.2 顶部操作区

| 元素 | 说明 |
|---|---|
| 返回供应商列表链接 | 返回列表页入口 |
| 供应商名称（大字） | 页面主标题 |
| 类型标签 | 展示供应商类型 |
| 所在城市 | 展示供应商所属城市 |
| 建档时间 | 展示建档时间 |
| 编辑按钮 | 进入编辑 |
| 删除按钮 | 执行删除 |

> 决策依据：不新增"合作状态"字段，顶部操作区固定展示"类型标签 + 所在城市 + 建档时间"（已确认决策 6）。

### 3.3 左栏：供应商基本信息

展示内容：名称、类型、城市、地址、联系人、电话、微信、描述、评分、建档人、建档时间。

排布要求：紧凑两列展示，控制行高，避免大段留白。

### 3.4 中栏：三个卡片区块

按顺序堆叠展示：图片管理 → 历史价格 → 评价。

## 4. 同城市供应商导航需求

### 4.1 基本规则

| 项 | 需求 |
|---|---|
| 导航范围 | 同城市**全部类型**供应商 |
| 标题 | 「同城市供应商」+ 总数「共 N 家」 |
| 搜索 | 搜索框输入即过滤（前端本地过滤名称） |
| 列表项 | 供应商名称 + 类型标签小字 |
| 当前供应商 | 高亮显示（主色浅底 + 左边框） |
| 点击行为 | 点击其他供应商名称 → 进入对应供应商详情页 |
| 重复排除 | 当前供应商不得重复显示为其他供应商 |
| 空状态 | 城市信息缺失时展示「该供应商暂无城市信息，无法展示同城市供应商」 |

### 4.2 已绑定置顶（仅酒店 / 打印店详情页）

| 项 | 需求 |
|---|---|
| 置顶范围 | 同城列表内**已绑定供应商**置顶显示 |
| 标记 | 置顶项带蓝色「已绑定」标记 |
| 跨城绑定 | 不混入右侧导航（绑定时已做同城限制，跨城绑定不进入同城列表） |

> 决策依据：同城导航范围为同城市全部类型；酒店/打印店场景已绑定供应商置顶；跨城绑定不混入（已确认决策 1）。

### 4.3 数据获取

复用现有 `GET /api/supplier/list`（cityId 过滤），`size=200`；超出按总数提示；**不新增接口**。

> 决策依据：数据获取复用现有 list 接口，size=200，超出按总数提示（已确认决策 2）。

## 9. 开发约束

1. **优先复用接口**：同城导航、图片、价格、评价均复用现有接口，不新增后端接口。
2. **不改数据库**：不新增表、不改字段、不调整城市字典。
3. **权限校验**：前端按钮沿用 `v-permission` 指令，后端权限规则以最新生效脚本 `20261101_open_supplier_permission.sql` 为准。
4. **前后端联调**：三栏渲染、同城导航跳转、图片交互、价格全量替换、评价提交需前后端联调验证。
5. **回归测试**：改造不得影响供应商列表、绑定关系、其他模块功能。
