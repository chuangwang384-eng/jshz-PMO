# 知识星球维护人角色与权限 - 设计说明

- 日期：2026-10-27
- 版本：1.006
- 关联迁移：database/migration/20261027_add_knowledge_maintainer_role.sql

## 1. 背景

知识星球（知识文档库）原由 ADMIN 角色持 `knowledge:manage` 统一管理，普通员工仅浏览。需求调整：

1. 新增独立角色「知识星球维护人」（KNOWLEDGE_MAINTAINER），专职知识文档管理；
2. ADMIN 不再默认拥有知识星球管理权（移除 `knowledge:manage` 及绑定）；
3. 维护人可上传 / 更新 / 下架 / 上架 / 永久删除 / 查看版本历史 / 查看下载次数；
4. 普通用户仅浏览 / 收藏 / 预览 / 下载；下架文档从收藏列表隐藏，上架后恢复；
5. 下架 / 上架 / 更新时通知相关用户（上传人、收藏者），操作写操作日志。

## 2. 权限模型

| 项 | 值 |
|----|----|
| 权限码 | `knowledge:maintain`（一码多路径，DbPermissionFilter 按 method+path 命中） |
| 路径绑定 | POST /api/knowledge/docs；PUT /api/knowledge/docs/**；DELETE /api/knowledge/docs/**；POST /api/knowledge/docs/*/relist；GET /api/knowledge/docs/*/versions |
| 角色 | KNOWLEDGE_MAINTAINER（builtin=1） |
| 兜底 | SUPER_ADMIN 由 PermissionService 强制全权，不受角色绑定影响 |

权限矩阵：

| 接口 | 维护人 | 普通用户 | 未登录 |
|------|--------|----------|--------|
| 列表 / 预览 / 下载 / 收藏 | 可 | 可 | 拦截 |
| 上传 / 更新 | 可 | 拦截 | 拦截 |
| 下架 / 上架 / 永久删除 / 版本历史 | 可 | 拦截 | 拦截 |
| 下载次数（列表字段） | 可见 | 隐藏（null） | - |

## 3. 业务联动

- 下架：`status=0`；收藏列表 myFavorites 仅展示 status=1，实现隐藏；通知上传人 + 全部收藏者（TYPE_DOC_OFF_SHELF）；
- 上架：新增 `POST /api/knowledge/docs/{id}/relist`，`status=1`；收藏列表自动恢复；通知全部收藏者（TYPE_DOC_RELISTED）；
- 更新：通知收藏者（TYPE_DOC_UPDATED）；
- 永久删除：通知收藏者（TYPE_DOC_DELETED）。

## 4. 兼容性

- 未转授维护人角色的老 ADMIN 将失去知识星球管理入口，由管理员在角色管理中绑定 KNOWLEDGE_MAINTAINER；
- 迁移脚本幂等，可重复执行；执行后需重启后端刷新 PermissionService 缓存。

## 5. 验收要点

- 数据库：permission/role/role_permission 绑定正确，`knowledge:manage` 已清除；
- 接口：未登录访问管理类接口 401；登录后无 `knowledge:maintain` 被 403；
- 前端：维护人可见上传中心与操作列（含上架按钮），普通用户隐藏。
