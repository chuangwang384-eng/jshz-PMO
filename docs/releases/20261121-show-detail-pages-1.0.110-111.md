# 发布与回滚记录：1.0.110/1.0.111 专家详情页与结构收敛（detail-pages / fs-hotfix）

- 发布时间：2026-11-21 13:20–13:25（1.0.110）、13:34–13:38（1.0.111 hotfix）
- ReleaseId：`1.0.110-detail-pages`、`1.0.111-fs-hotfix`

## 背景（用户五项反馈）

1. 不要单独一张头像占一页（出场页）；
2. 专家信息页：大会角色+头像放左侧、简介右侧，简介尽量单列、放不下再两列；
3. 编辑模式下支持批量调整简介字号；
4. 多人同章节的过场页要有标题+专家头像；
5. 「重复识别」问题（同环节同一专家出现多次）+ 向导需支持新增/删除页面（无匹配专家环节可手动加文字页）。

## 内容

- **出场页（bio）取消生成**，信息并入**专家详情页**（新简历页布局）：左栏大圆头像+大会角色徽章+流光姓名+单位；右栏「个人简历 RESUME」+条目列表（**≤8 条单列，>8 条自动两列**）。旧 bio 渲染路径保留（兼容旧草稿），向导不再生成。
- **过场页多人头像**：章节过场页显示编号+流光标题+**章节全体出场专家圆头像（≤6 人，无照片显示姓氏占位圆）**+姓名。
- **页内简介字号批量调整**：`Slide` 新增 `fontSize` 档位；编辑模式下简历页出现「简介 A− / A＋ / 恢复默认」工具条，按页批量调整（0.7–1.5 倍），「保存修改」写回 fontSize 并重新渲染。
- **重复识别修复**：日程解析在同环节产生同一专家多条记录且匹配未去重——`matchSpeakers` 按专家 ID/姓名去重（环节内不再出现重复 chip）。
- **页面增删入口**：向导第四步页面清单每页可「删除」（封面/致谢不可删）、可从环节下拉「添加文字页（不放头像，仅文字）」插入致谢页前——无匹配专家环节的兜底操作入口。

## 事件记录

- 1.0.110 发布后冒烟发现 `--rfs` 字号档未渲染：`resolvePhotos` 重建 Slide 时 fontSize 被丢弃（补丁插 null）。1.0.111 修复为透传 `slide.fontSize()` 并补单测断言。两次编排均一次成功。

## 验证

- 后端全量 **228 测试绿**（含 fontSize 传递断言、照片池、五类页面）；前端构建 is-not-exported=0。
- 发布后冒烟（1.0.111）：`--rfs:1.2` 渲染命中、rp2-avatar/sec-people/fs-bar 全命中。
- 真机待用户实测：专家详情页布局、过场页头像、字号工具条、页面增删。
