## 1. 需求与共性研究结论

Owner 提供历史结算单/成本单/预算单 4 份 + 公司报价单/成本单模板 2 份，共性结构：
1. 表头信息区（项目名称/时间/地点/客户/负责人）
2. 费用大类分节明细（单价×数量=小计，分节小计）
3. 汇总链：费用合计 → 服务费 6% → 不含税总价 → 增值税 6% → 含税总价
4. 公司内部同一费用项库两价口径：成本价 / 对外报价（报价单多"最低利润要求"列），报价−成本=毛利
