## 问题与修复

### 抠图"仍有问题"（1.0.62 后段战锋依旧、任婧蓝边）

- **复核方法**：从生产 jar 解出 worker（MD5 与仓库一致）+ 模拟 Java `resizePortraitInput` 预缩放，逐张复现。
- **根因 1（段战锋）**：他的底是**深红色**（非白底）——深棕发与深红底的色距仅 ~45，低于彩色分支容差 64，整片头发被当背景删；眉眼随后续链路受损。二分定位：禁用 strip 后基础链（u2net 掩码+闭运算+填洞+主体）**完全正常**，元凶即 strip。
- **根因 2（任婧蓝边）**：发际蓝影残留块位于轮廓内部（夹在头发与肩膀之间），1.0.62 的"邻接外部才清理"规则放过它们。
- **修复**：strip 残留判定增加**饱和度判别**——与背景同色系的残留（含阴影）饱和度必然接近背景（|Δsat|≤0.3），而深棕发饱和度 ~0.2 与深红底 ~1.0 迥异；配合统一邻接规则。删除无效的暗部回收实验代码（未进过生产）。

### 杨晨简介.docx 只识别出姓名

- **根因**：设计版式把姓名/单位/职称放在**文本框**（`w:txbxContent`），`XWPFWordExtractor` 只读顶层段落。
- **修复**：`parseDocx` 增加 `extractDocxTextBoxText`（XmlBean selectPath 抽取全部文本框段落，按行拼接后并入正文）。
