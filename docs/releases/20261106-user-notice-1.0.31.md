## 通知正文（可直接复制）

**关于系统升级、需要重新登录一次的通知**

各位同事：

公司内网管理系统（jshz-PMO）已于【发布时间】完成 v1.0.31 升级，本次为安全与稳定性修复，主要内容包括：账号停用/删除/改密/角色调整后旧登录立即失效、下架的知识文档不再允许下载、大文件上传后的解析改为后台处理（上传更快）。

**请全体同事重新登录一次**：升级后原有的登录状态会失效，打开系统时如提示「登录已过期」，重新输入账号密码即可，数据不受影响。这是本次安全升级的预期行为，不是系统故障。

另外两点使用变化：

1. 上传 PDF / Word / Excel 后，列表中的解析状态会先显示「处理中」，稍后变为「成功」；解析结果不影响文件本身，文件可正常下载预览。
2. 管理员停用账号、重置密码或调整角色后，该账号在其它设备上的旧登录会立即失效，需重新登录。

使用中如遇异常，请联系 PMO / 系统管理员反馈。
