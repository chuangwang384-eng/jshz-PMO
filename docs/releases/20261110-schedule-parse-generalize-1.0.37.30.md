## 2. 实际变更（ScheduleParseService.java）

- **列头空白归一化**：`compactCell()` 去全角空格/\u00a0/\s（修 ④）；
- **列映射修正**：讲题列优先判为主题列，讲者列判定排除「讲题」（修 ①）；
- **人名判定重构**：弃用任意 2-4 汉字滑窗（NAME_WITH_TITLE 删除），改为**按分隔符切 token 逐个判名**——纯 2-4 汉字 token 或剥头衔后缀后 2-4 汉字才算名；连续单字 token 两两合并（「王 军」→王军，修 ②⑤⑦）；
- **不可见字符清洗**：PUA \uE000-\uF8FF、零宽字符剔除（修 ⑤）；

- **表内主持行**：无讲者/主题名时，含「主持」的单元格提取为大会主持（修 ③）；
