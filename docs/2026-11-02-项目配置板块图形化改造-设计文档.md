# 项目配置板块图形化改造 设计文档

- 版本：v1.0
- 日期：2026-11-02
- 技术栈：Vue 3.4 + Element Plus 2.7 + Pinia 2.1 + vue-flow

## 1. 总体方案

前端为主改造：新增流程可视化组件 + 三步向导，复用现有 `/api/project/config/**` 接口与 5 张配置表，后端零改动。`ProjectConfig.vue` 改造为「视图切换 + 流程总览区 + 三步向导」结构。

## 4. 数据流

- 加载：现有 loadTypes / loadPhases / loadTemplates / loadTypePhases / loadPhaseTemplates → Pinia store 统一缓存 → 图形与表格共享；
- 保存：Step1 保存 project_type（新增/更新）；Step2 保存 type_phase_rel（按 sort 增量或全量重写）；Step3 保存 phase_template_rel（区分全局 type_id=0 与类型专属）；
- 拖拽排序：vue-flow 节点位置变化 → 依 order 计算 sort → 调用现有排序保存参数（saveTypePhases / savePhaseTemplates）；
- 兜底语义：加载时 fallback 标记保留，TemplateCard 展示来源徽标（全局/专属/被覆盖）。

## 5. vue-flow 集成要点

- 依赖：`@vue-flow/core`（+ `@vue-flow/background`、`@vue-flow/controls` 按需）；
- 节点：自定义节点类型 phaseNode（阶段卡片：名称、排序、模板数、必填数徽标）；模板卡片内嵌于阶段展开态；
- 边：直线/折线边，从上一阶段指向下一阶段；
- 拖拽：nodesDraggable=true；onNodeDragStop 计算新顺序写回；
- 只读模式（总览图）与编辑模式（向导 Step2/3）通过 prop 切换；
- 数据映射：type_phase_rel.sort → 节点 order；phase_template_rel.sort → 卡片 order。

## 6. 状态管理（Pinia）

- store：`src/stores/projectConfig.js`：types / phases / templates / typePhaseRels / phaseTemplateRels / activeView / wizardState；
- actions：loadAll / saveType / saveTypePhases / savePhaseTemplates / toggleView。
