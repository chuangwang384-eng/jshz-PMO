## 流程覆盖

两张流程图作为业务核对依据。现有系统支持七类线下费用和线上标准报价的录入，能按行计算金额并合计。下表区分已有入口和仍需人工处理的业务规则。

| 流程 | 现有覆盖 | 差距 |
| --- | --- | --- |
| 线上会议 | 配置收费标准、选项报价、手填费用、内部确认 | 未见对客报价导出、发送或客户确认记录 |
| 酒店 | 场地、住宿、用餐、茶歇四行，可增行 | 酒店推荐确认、外埠住宿估算及无外埠预留两间、会前或会后集中用餐、提前到达用餐两种估法、茶歇约减 30% 和 5/10 倍数取整、档位与客户确认均需人工处理 |
| 交通 | 大交通、车队、平台三行 | 飞机 2000 元/人、高铁一等座取整、车队单价与人数乘 2、平台按城市 200/100 每人及不覆盖选项未结构化 |
| 搭建 | 签到背景板、LED、影音行，可移除分节 | 直播设备细项和按需启用由人工决定 |
| 物料 | 设计、串场与沟通函、日程台卡、展架、条幅、打印、花束均有行，部分价格有默认值 | 缺少有无主视觉的设计分支。日程加量 5–10 张、台卡加量 10–20 张和每场 4 个展架目前走单价预填，不能据此自动估算。条幅尺寸和其他花束仍需人工报价 |
| 媒体与礼品 | 媒体行与可选分节，礼品有 200–300 单价提示 | 摄影需求及客户是否确认礼品未结构化 |
| 人员 | 默认 500 元/人/天和实际报销行 | 人数与天数需手算合并，交通住宿报销金额需人工录入 |

优先复用现有明细，按参会人数、外埠人数、场次、城市档位、人员和天数生成可编辑草稿。收费标准应区分单价、数量增量与按场数量，保留估算依据。报价版本在内部确认后可用于导出及记录客户确认。舍入、价格快照、客户回执和阶段门槛待业务确认，本次实现范围为下述两项缺陷。
