## 范围与状态

- 主责 Codex，2026-11-20。基线为 main 的 381bbaa，生产直连和代理在工作开始时均为 1.0.81（e3ba372）。
- 修复 Word 长段落中的医院和科室、PowerPoint 职称后仍含学组职务、以科结尾的姓名误入科室，以及中文图片简历 OCR。

## 实现与验证

- ResumeParseService 分句匹配医院和科室，识别任职组合中的医生职称。独立职称仍从正文提取。文件名与正文独立标题相互印证时，接受以科室后缀结尾的人名并从科室候选排除。
- 图片入口复用本机 PP-OCRv5 和置信度过滤，沿用 Tesseract 回退。临时图片由本地 OCR 工具清理，原件仅供本地测试。
- JDK 17 下通过简历解析器的正常入口复现四份原件的问题，语义模型和证件照服务在该回归中隔离。另在 ResumeParseServiceTest 加入独立于原件的三项回归。
- 发布后需登录专家库，重新上传四份原件检查预填结果，再验证已有照片和档案保存操作。生产业务验收另行记录。

- 用 scripts/build-all.ps1 -BackendOnly 生成隔离制品。正式发布使用 scripts/deploy-backend.ps1 的蓝绿切换，验证 8080 /health 和 Nginx /api/health 返回候选版本及提交号，专家库入口 200，匿名解析接口 401，线上 JAR 与候选一致。
