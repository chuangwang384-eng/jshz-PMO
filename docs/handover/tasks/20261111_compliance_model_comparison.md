## 本轮调整

- 对 PDF 的独立抬头和章节说明采用保守过滤，保留真正包含内容的章节段落。
- 正文标题突出适用对象和执行条件。补齐专家与听众比例及劳务标准、同天同场计发规则。正文、金额和既有分段沿用原文候选。
- 本地 LLM 兜底提示增加反例和 OCR 核对口径。线上正常路径仍由结构化原文及标题规则生成候选。
- 云端仅用于此次对照。无需更换模型、接入新服务或改动数据库。含扫描表格的金额符号、收费条件和 OCR 缺损仍需对照原件。
