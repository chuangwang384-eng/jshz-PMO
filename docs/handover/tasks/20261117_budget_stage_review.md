## 优先修复

1. 线上标准项勾选后数量置为 1，但 ProjectBudgetPanel.vue 在数量小于等于 1 时只显示文本。应允许已选项编辑数量，补测 1 → 3 → 保存重开仍为 3。
2. ProjectBudgetController 的独立 POST 确认接口将服务返回的 ProjectBudgetItem 实体按 Map 过滤，并把 ProjectBudget 实体也按 Map 读取。随后调用整单覆盖保存会传入空明细和空备注。当前页面使用 PUT，独立接口仍存在清空金额、明细和备注的风险。建议确认已保存草稿时保留原明细、合计和备注，补端点回归。
3. ProjectBudgetPanel 只检查是否存在有名称的行，ProjectBudgetService 允许空明细确认，也允许用 confirm=true 覆盖已确认单。建议先定零金额例外与更正权限，再做服务端校验、状态控制及草稿并发覆盖保护。
4. 线下模板的日程上浮、台卡上浮、每场易拉宝数量经 feeItem 预填到单价列。应将该类收费标准作为数量规则，并保留编辑权限。隐藏/恢复可选分节目前只恢复分节标题，建议在保存前支持撤销并恢复本次录入的行。
