# 串场向导单页预览与专家头像 1.0.121

- 主责 Codex，2026-11-21。基线 main b6f9a46，生产基线 1.0.120。
- 专家资料池按专家库 ID 去重。无 ID 的记录仅在规范姓名唯一匹配时复用已关联资料；不同专家库 ID 的同名记录维持各自资料。第三步保留每个环节的角色及时间。
- 第三步按环节显示过场页及简介页卡片，每张卡片可打开正式版式。页面清单也可逐页预览。使用现有项目预览接口，单页 iframe 以独立沙箱载入。
- 专家照片通过现有登录态文件接口读取，由浏览器解码与缩小，圆形裁剪结果优先。未进入裁剪界面时用已解码照片，预览等待专家照片读取完成。继续使用既有照片池。
- 生成的封面、过场页及自动添加的文字页移除时间。时间仍用于日程与角色步骤核对和排序。历史归档文件保持原样。
- 无数据库迁移、API 契约、权限或配置变更。上线前运行 release-full 预检，备份后切换；回滚指向发布前 1.0.120 制品。
- 业务复验：同一专家跨多个环节只出现一张资料卡，且各环节角色可独立设置；大会主席开场致辞显示过场和专家简介两张卡片；两页打开后头像可见；正式文件封面及环节无会议时间。
