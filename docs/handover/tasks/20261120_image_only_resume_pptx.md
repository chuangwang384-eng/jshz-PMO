# 20261120 图片型 PPTX 简历 OCR

- 主责 Codex。代码基线为 main 867c3f7，生产基线为后端 1.0.82 / f2adcbb。
- 原件是单张满幅 JPEG 的一页 PPTX，幻灯片没有文本框或原生文字。旧版 Maven 原件重现测试报「未识别到有效文本」。图片在旧版只进入证件照候选流程。
- ResumeParseService 在整份演示文稿无正文时，用首张直接放置、宽高分别至少占幻灯片 60% 的图片做本机 OCR，对较小截图按比例放大至最多两倍且最长边不超过 2200 像素，再复用 PP-OCRv5 和 Tesseract 回退。文件已有正文时维持原生提取；普通小图片继续用于照片候选。每次 PPT/PPTX 解析至多额外调用一次图片识别流程，避免长文稿逐页 OCR 的开销。
- 回归覆盖满幅截图、原生文本优先、小图片、真实原件和上一轮四份原件。原件测试使用本地文件、隔离语义模型与照片模型，原件不纳入版本库。
- 版本 1.0.83 仅发布后端。既有 API、权限、存储策略和模型配置继续使用，无数据库迁移。
- 回滚以 builds/1.0.82-build-20261120_083320/expert-system.jar 为已验证基线。后端正式发布依旧使用蓝绿脚本，发布后核对双健康、线上和回滚制品哈希、专家库入口和匿名权限。
- 接手先读取生产直连和代理健康端点，核对发布记录。架构和部署说明已同步。生产登录后的原件预填和照片预览另行验收。
