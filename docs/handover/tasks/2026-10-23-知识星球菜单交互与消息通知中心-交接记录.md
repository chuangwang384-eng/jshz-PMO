### 3.3 消息通知中心

**表结构**（`database/migration/20261023_add_notification_table.sql`，幂等）：

```
notification (
  id BIGINT PK AI,
  user_id BIGINT NOT NULL,          -- 接收人
  type VARCHAR(50) NOT NULL,        -- approval_result / approval_todo / role_changed / password_reset / doc_off_shelf / doc_deleted（扩展点）
  title VARCHAR(200), content VARCHAR(500),
  jump_path VARCHAR(200),           -- 点击跳转路由
  is_read TINYINT DEFAULT 0,
  create_time DATETIME, read_time DATETIME NULL,
  KEY idx_user_read_time (user_id, is_read, create_time)
)
```

**后端接口**（均登录即可，仅查本人）：

| 接口 | 说明 |
|---|---|
| `GET /api/notifications?page=&pageSize=` | 分页列表（时间倒序） |
| `GET /api/notifications/unread-count` | 未读数 |
| `POST /api/notifications/{id}/read` | 单条已读 |
| `POST /api/notifications/read-all` | 全部已读 |

**业务埋点**：

| 触发点 | type | 接收人 | jump_path |
|---|---|---|---|
| 审批通过/驳回（ApprovalService.approve/reject） | approval_result | 申请人 | `/profile/my-approvals?status=1\|2` |
| 新申请提交（submitRequest/submitCreateRequest） | approval_todo | 审批角色下全部用户 | `/admin/approval/manage?status=0` |
| 角色调整（UserService.assignRoles） | role_changed | 被调整用户 | `/profile` |
| 密码重置（UserService.resetPassword） | password_reset | 该用户 | `/profile/change-password` |
| 文档下架（offShelf） | doc_off_shelf | 上传人（username 反查 userId，查不到跳过） | `/knowledge-planet` |
| 文档永久删除（permanentDelete） | doc_deleted | 上传人（同上容错） | `/knowledge-planet` |

**前端**：

- `api/notification.js`、`store/notification.js`（30 秒轮询，登录启动、退出清理）、`components/NotificationBell.vue`（铃铛 + 未读红点 + 消息列表，未读置顶加粗、单条已读、全部已读、分页 20）。
