## 口径

Codex 从原件的 PPTX 文本框、表格和内嵌图片，以及 PDF 渲染、DOCX 和 Excel 单元格，整理原文参照。每条是一次具名出场。合并主持格计一次，时间取覆盖区间。明确议题缺失时留空。开场、总结同人且原件无单独主席标签的个别记录，按本轮主席业务口径推断，仍可由维护人复核。

参照与本地候选通过多重集一对一匹配。姓名和议题去空白并统一全半角，时间统一连字符及小时补零。议题文字差异仍计失配。Codex 参照尚未经第二人审核，因此本表是首轮估算，不能独立衡量 Codex 自身准确率。样本刻意包含低候选文件，也含同一会议的 PDF 和 Word 版本，不能代表 77 份全量。

本地规则来自本地开场主席修复后的构建代码。完整本地链路执行同一解析器及本机 qwen2.5:3b，绕过专家库查询和业务写入。未将原件发送给其他服务。

## 差异与优化优先级

1. 图片 PPTX 和扫描 PDF。逐页用文字覆盖率判断是否需要本地 OCR，保留文字框坐标，并恢复表格横纵线和合并格。节目单和仅封面样本应返回未发现会议出场。
2. 分离文本框和特殊时间格式。按纵坐标、同页列位置绑定姓名与时间；仅在时间区域规范化 OCR 空格和分隔符，保留原文议题。
3. 原生表格合并格。横向合并时识别议题与名单，纵向合并主持按覆盖区间输出一次；主题列表用明确分隔符保留首位人名。
4. 本地语义兜底只收未覆盖行。候选须回指姓名、角色、议题、时间的页或行证据。以出场去重，允许同一人跨角色；限制生成长度和兜底时间。
5. 复评时将同会不同文件归入同组。先冻结这 12 份做调试回归，再用另外的会议作为独立验收集。四字段 F1 ≥95%，同时记录精确率、召回率和失败文件。
