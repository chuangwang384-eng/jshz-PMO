## 接口及回滚

- `GET /api/project/{id}/closeout/{phaseId}` 的 `completed` 代表项目正式完成。新增 `canComplete`，页面还检查适用事项是否全部确认。详情新增 `canReopen`。
- `PUT /api/project/{id}/complete` 和 `PUT /api/project/{id}/reopen` 由服务端校验权限和状态，后者接受 `{reason}`。完结及重新打开使用项目行锁。凭证沿用结项上传接口及项目文件鉴权。
- 无表结构、数据迁移或新权限码。旧版不能识别 `COMPLETED` 的只读和筛选语义，存在已完成记录后的回滚应先确认状态兼容方案并取得生产操作批准。
