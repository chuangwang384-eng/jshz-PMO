# 串场封面文本框与头像框对齐

- 主责 Codex，2026-11-21。基线 main 618ba83，生产发布基线 1.0.122。分支 codex/show-cover-controls。
- 串场向导暂停显示公司共享模板入口，既有存储与 API 保留。内置主题、项目背景仍可使用。
- 点击封面文本框可选择字体与字号，拖拽右下角调整宽高，右上角删除，默认字段可恢复。方向键可移动文本框或调整所聚焦缩放手柄。尺寸、字体与内容随既有项目草稿保存。
- 字体来源为 Google Fonts 上游项目 [马善政毛笔楷书](https://github.com/googlefonts/mashanzheng) 与 [志莽行书](https://github.com/googlefonts/zhimangxing)。遵循 SIL OFL 1.1。以 WOFF2 分块打包，离线稿仅内嵌所用字体的字符分块及许可证。
- 头像框保持素材原始比例，头像默认缩至框的 82%。专家步骤可调整内层头像大小和横纵偏移，配置保存在项目草稿，裁剪预览、过场页、专家简介页共用对齐参数。
- 扩充既有 deck 的 coverFields 和 frameFit 属性；旧稿件缺少新属性时使用默认值。无需数据库迁移。
- 生产复验：选择带透明装饰框的项目，调小或平移头像，核对裁剪结果与正式演示；删大会主席字段，调整主标题框大小和字体，保存后重开向导并断网预览归档 HTML。
