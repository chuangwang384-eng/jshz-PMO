# 多文件上传、结算资料包和项目文件名

- 2026-11-25，主责 Codex。基线 main `1bb708c`，生产核实 `1.0.145 / 866811f`。实施分支 `codex/settlement-package`，之前的结算资料功能已在 main。
- 各细项支持逐次选文件、移除待选并提交、追加到当前已提交批次。原替换和多版本操作保留。追加批次继续遵守合计文件数、大小、权限和阶段限制。

- 扩展结算提交接口并新增归档 API。沿用项目文件、上传口权限及项目资料库存储，无数据库迁移或配置变更。需求和架构说明同步。

- 回滚通过发布编排恢复 1.0.145 前后端。已追加的资料以现有批次格式保存，ZIP 实体和元数据保留。旧版可能将 ZIP 识别为结算细项文件之外的未展示附件，重新发布新版本后可继续使用。
