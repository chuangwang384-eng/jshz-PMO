# 结算单文件删除与资料包目录

- 2026-11-25，主责 Codex，独立分支 `codex/settlement-file-delete`。基线 main `ecd55b7`，生产核实为 1.0.146 / 989b58b。
- 在可编辑的当前批次文件行提供删除确认。服务端校验项目成员、适用细项、阶段、当前批次和文件 ID。操作软删并记录日志，无数据库迁移或配置变更。保留历史批次和已存在的固定 ZIP。
- 新归档按「业务小节/资料细项/文件」分层，例 `供应商费用核对/酒店发票/文件.pdf`。删除最后一个必填文件后，可补传，归档和向后推进前重新核对。
- 实际业务验收：有权限的成员在同一细项上传两份文件，删除其中一份并确认另一份仍可下载。版本口删光当前批次后历史依旧可见，当前必填变为待提交。再次归档后核对 ZIP 的两级目录和文件。未登录和不可编辑用户不能删除。
- 授权回滚恢复 1.0.146 前后端。软删除记录留痕，旧版本的推进行为可能重新识别此前仍有效的历史批次，回滚期间应核对该情况。
