# PMO 防御性安全审查清单

## 1. 确定入口与预期权限

- 读取当前仓库 `AGENTS.md` 第 4–7 节及相关需求。按本次变更定位路由、Controller、API 权限规则、Service 的资源校验、查询条件和文件存储。用代码确认对象归属和权限规则，分别记录页面入口和直接 API。
- 仅安全审查时以源码、配置和已有测试为证据。需要验证时用隔离环境、合成账号和文件，调用正常业务接口验证允许与拒绝。线上验证遵循授权范围，真实资料留在批准的环境内。发现疑似泄露或越权时，记录脱敏证据并按仓库规则处理相关发布。

## 2. 按变更选择检查项

| 范围 | 核对项 |
| --- | --- |
| 登录、角色与项目数据范围 | 确认 DB API 权限规则实际命中顺序，Service 仍检查资源级权限。按实际业务角色核对读取与写入，覆盖未登录、已登录非成员、其他项目成员、本项目有权成员，以及适用的全局角色。列表、详情、导出和聚合统计使用一致的数据范围。 |
| 上传、预览、下载和删除 | 校验项目、阶段、细项、文件 ID 的关联与当前状态。直接文件路径、预览、下载、导出接口同样执行对象权限。验证软删、历史版本和旧链接符合业务规则。文件类型、大小、批次总量、存储路径和归档条目命名由服务端校验。 |
| 归档、替换及并发 | 检查多文件上传部分失败、追加与删除并发、重试、推进或归档并发时的状态。重点核实空批次是否误提升历史、ZIP 是否收录了不应收录的资料、失败是否保留上一份有效归档。 |
| 敏感资料与日志 | 按专家简历、头像、证件、财务票据的用途核对最小字段、响应和导出范围。检查脱敏、临时文件、预览缓存、测试样本、异常和操作日志。审查证据用合成值或脱敏标识。 |
| OCR、知识库或 Agent | 沿原始文件、解析结果、索引、检索和导出核对数据范围。检查撤权或删除后的旧索引与缓存，注明模型服务和数据去向。 |

## 3. 形成可核对的结论

- 按适用的角色及资源关系写明预期结果、实测结果和证据。匿名请求返回 401 只证明登录拦截，项目数据范围以已登录的允许及拒绝结果为准。
- 每个发现记录严重度、文件和行号、受影响入口和角色、预期与实际、修复建议及回归用例。单独标记仅静态推断、已实测和待验证的项。生产技术冒烟与登录后的业务权限验收分别记证据。
